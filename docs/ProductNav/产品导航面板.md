> 素材位置：[`src/lib/product-nav/`](../../src/lib/product-nav/)

点顶栏左上角 3×3 点阵弹出的**产品类导航弹层**：5 列等宽、顶部按名称搜索、每列一个产品（同列可堆叠多个产品）、每条服务前带浅蓝圆角线性图标。

从「算力加速平台」1:1 还原页里抽出，几何与配色均按 2× 截图实测折算为 CSS px。

## 2. 视觉规格

| 项 | 值 |
| --- | --- |
| 弹窗 | `absolute left-[12px] top-[8px] z-50`，宽 1040、`max-h calc(100%-16px)`，圆角 8、边框 `#E5E6EB`、阴影 `0 8px 28px rgba(0,0,0,.14)`，白底 |

| 产品标题 | 28px 浅蓝圆角图标（`#EEF2FD` / 圆角 8）+ 11px 间距 + 16px 半粗 `#1D2129`，下距 10 |
| 服务行 | 30px 高；18px 图标（圆角 5）+ 11px 间距 + 14px 文字；一级项（无分组）34px 高、15px 字 |
| 分组标题 | 9px 蓝点 `#1C5BD6` + 14px 灰字 `#4E5969`，行高 28，组间上距 10 |
| 缩进 | 一级服务 0；分组标题 +1px；分组内服务 +15px |
| 同列多产品 | 第二个及以后的产品与上一产品间距 32px |
| 交互 | 悬停 `#F5F7FB`；`Esc` / 点卡片外 / 再点 9 宫格关闭；搜索命中服务名或分组名即保留整组，全空显示「未找到相关服务」 |

设计取舍：**是浮在页面上的下拉弹窗，不是盖满整页的白色浮层**——四周留出 12/8px，底层页面仍可见可辨。

## 3. 数据形态

「列 → 产品段 → 分组 → 服务」，与侧栏的 `ShellNavRow` 完全独立、互不派生：

```ts
interface ShellPanelColumn { sections: ShellPanelSection[] }
interface ShellPanelSection { title: string; icon: string; groups: ShellPanelGroup[] }
interface ShellPanelGroup { label?: string; items: ShellPanelItem[]; visibleTo?: 'admin' }  // 无 label = 产品直挂项
interface ShellPanelItem { label: string; icon: string; visibleTo?: 'admin' }               // icon 为 NAV_ICONS 的 key
```

`visibleTo` 是**可选的导航层可见性**：不填 = 所有已登录用户可见，填 `'admin'` = 仅平台管理员可见。它只负责"不显示"，真正的鉴权要靠路由守卫；过滤在组件内完成，摘空的分组/产品/整列会连壳一起消失，不留空位。

`icon` 只写 key（如 `'Gauge'` / `'BrainCircuit'`），不写组件；缺图标时在 `icons.tsx` 的 `NAV_ICONS` 里补一条即可，组件会自动兜底。

## 4. 最小接入

```tsx
import { useState } from 'react'
import { PlatformHeader } from '@/lib/platform-shell'
import { ProductNav, CALSPEED_PRODUCT_NAV, type ShellPanelItem } from '@/lib/product-nav'

const [navOpen, setNavOpen] = useState(false)

<div className="h-[calc(100vh-68px)] flex flex-col overflow-hidden">
  <PlatformHeader productName="算力加速平台" onNavClick={() => setNavOpen((v) => !v)} {...账号 props} />
  <div className="flex flex-1 overflow-hidden relative">
    <SideNav rows={rows} menuTitle="…" />
    <div className="flex-1 relative">{children}</div>
    {navOpen && (
      <ProductNav
        columns={CALSPEED_PRODUCT_NAV}
        role={currentRole}   // 'admin' | 'user'，默认 'admin'（不传即现有行为）
        onClose={() => setNavOpen(false)}
        onItemClick={(item: ShellPanelItem) => {
          setNavOpen(false)
          // 跳转由使用方决定：路由、切换产品、或什么都不做
        }}
      />
    )}
  </div>
</div>
```

要点：

- 父容器必须 `relative`（弹窗用 `absolute` 定位），且不要让祖先裁掉溢出；
- `onNavClick` 不传时 9 宫格保持纯展示（不会变成可点按钮）；
- `onItemClick(item)` 只回传服务对象，**不带 path**，避免把路由写进素材；
- 面板根节点 `z-50`，页面内浮动按钮（如客服气泡）需低于该层级，否则会盖住弹窗。

## 5. 换一个产品/换一套导航

1. 复制 `presets/calspeedNav.tsx` 为 `presets/<product>.tsx`；
2. 只改文案与 `icon` key，不动组件；
3. 在页面里 `import { MY_PRESET } from '@/lib/product-nav/presets/<product>'`，传给 `columns`；
4. 若新产品的列数不是 5：列宽由 `flex-1` 自动均分，无需改组件；列数过多时把部分产品合到同列（同列堆叠）。

## 6. 注意事项

- ❌ 组件内不出现任何产品名/菜单文案/路由字符串；
- ❌ 不 import `react-router`，跳转一律走 `onItemClick`；
- ❌ 不为了通用改视觉：抽取前后尺寸、字号、间距逐像素一致；
- ✅ 旧路径 `@/lib/platform-shell` 仍可 `import { ProductNav, CALSPEED_PRODUCT_NAV, NavIcon, NAV_ICONS }`（兼容再导出），新代码请直接用 `@/lib/product-nav`；
- ✅ 改完跑 `npx tsc -b --force` + `npx vite build` + `node scripts/validate-all.js`，并在浏览器里量一遍 1040 宽、5 列、服务行 30px。
