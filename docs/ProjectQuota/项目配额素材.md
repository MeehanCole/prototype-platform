# 项目配额工作台素材

项目概览里的配额视图由「项目基本信息 + Tab + 容器配额 + 项目配额 + 管理弹窗」组成。把其中稳定的结构与视觉抽成素材，页面只保留业务状态、Mock 数据与业务弹窗（配额编辑 / 信息编辑 / 删除确认）。

## 组成

| 文件 | 作用 |
| --- | --- |
| `src/lib/project-quota/ProjectQuotaBoard.tsx` | 工作台主体、展示工具、弹窗骨架与按钮组 |
| `src/lib/project-quota/index.ts` | 桶文件，页面只能通过 `@/lib/project-quota` 引入 |
| `src/pages/算力加速平台/数据管理/项目配额/` | 真实使用方，负责注入图标、数据、业务弹窗和 PRD 批注 |

素材不含 `react-router`、页面路径、产品菜单、页面 meta 或 PRD 批注逻辑。

## 视觉规格

| 区域 | 规格 |
| --- | --- |
| 标题 | 28px / 40px 行高 / `#323232`，说明文字 14px / `#aaaaaa` |
| 基本信息卡 | 4 列栅格，字段上行值 13px / `#1d2129`、下行标签 12px / `#86909c`，卡边距 20px 16px |
| 管理按钮 | 32px 高，主色 `#166eff`，气泡菜单 152px 宽，右上角 4px 小三角 |
| Tab 栏 | 浅灰底 `#f5f6fa`，选中项主色实心 + 白字，未选中项 13px / `#4e5969` |
| 配额长条卡 | 4 列：34% / 22% / 22% / 22%，描边 `#e9edf2`，底色 `#f9fbfd`，间距 10px |
| 弹窗 | 600px 宽，圆角 4px，头部/内容/底部三段，关闭图标由调用方注入 |
| 删除空态 | 主内容区居中，圆形图标底 `#f2f3f5`，撤销按钮 32px 高 |

## Props 清单

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `info` | `ProjectQuotaInfo` | 基本信息卡字段 |
| `containerRows` | `ProjectQuotaRow[]` | 容器配额原始行，包含 CPU/内存的请求与限制 |
| `containerGroups` | `ProjectQuotaContainerGroup[]` | 容器配额分组，声明每组取哪两个 `key` 作为请求/限制 |
| `projectRows` | `ProjectQuotaRow[]` | 项目配额行 |
| `tabs` / `quotaTab` / `activeTab` | `string` | Tab 列表、配额 Tab 标识与当前项 |
| `sectionTitles` | `{ containerQuota, projectQuota }` | 两个区块标题 |
| `icons` | `ProjectQuotaIcons` | 基本信息图标与资源图标工厂；图标库由调用方决定 |
| `title` / `description` | `string` | 页头文案 |
| `manageItems` | `Array<{ key, label, icon }>` | 管理菜单项，删除项固定由 `onDelete` 处理 |
| `deleted` / `deletedView` | `boolean` / `ReactNode` | 删除空态完全由调用方提供 |
| `extra` | `ReactNode` | 业务弹窗、轻提示等覆盖层插槽 |
| `onTabChange` / `onManageItem` / `onDelete` | callback | 交互回调 |

工具函数 `quotaText` / `usedText` / `remainText` 也随素材导出，便于页面和 demo 共用同一套展示规则。

## 最小接入

```tsx
import {
  ProjectQuotaBoard,
  type ProjectQuotaInfo,
  type ProjectQuotaRow,
  type ProjectQuotaContainerGroup,
} from '@/lib/project-quota'

const groups: ProjectQuotaContainerGroup[] = [
  { key: 'cpu', label: 'CPU', icon: 'cpu', requestKey: 'cpuRequest', limitKey: 'cpuLimit' },
]

<ProjectQuotaBoard
  info={info}
  containerRows={containerRows}
  containerGroups={groups}
  projectRows={projectRows}
  tabs={['资源状态', '配额', '用量统计', '元数据']}
  quotaTab="配额"
  activeTab={activeTab}
  sectionTitles={{ containerQuota: '容器配额', projectQuota: '项目配额' }}
  icons={icons}
  title="项目概览"
  manageItems={manageItems}
  onTabChange={setActiveTab}
  onManageItem={openDialog}
  onDelete={openDeleteDialog}
/>
```

## 变更规则

- 视觉与布局调整只改 `src/lib/project-quota/`，并在真实页面回归。
- 业务字段、弹窗内容与 PRD 标注只改页面层，不得写进素材。
- 图标必须由调用方注入，素材内不绑定具体图标库。
- 删除后展示什么由 `deletedView` 决定，素材只负责腾出主内容区。
- 新增配额行或调整容器配额分组，改页面的 Mock 数据 / 分组配置，不改素材结构。
