## 1. 这份素材包含什么

| 组成 | 文件 | 说明 |
| --- | --- | --- |
| 顶栏 | `PlatformHeader.tsx` | 66px 高；Logo + 产品名 + 管理工作台胶囊 + 语言 + 通知 + 账号 |
| 左侧导航 | `SideNav.tsx` | 256px 宽；租户胶囊 + 菜单标题 + 多级菜单 + 收起按钮 |

| 产品导航面板 | `ProductNav.tsx` | 点顶栏左上角 9 宫格弹出的 5 列产品类导航（整页白底浮层 + 搜索） |
| 面板图标 | `navIcons.tsx` | 面板内浅蓝圆角底 + 蓝色线性图标，`NAV_ICONS` / `<NavIcon>` |
| 类型 | `types.ts` | `ShellNavRow` / `ShellTenant` / `PlatformShellPreset` 等 |
| 预设 | `presets/calspeed.tsx` | 「算力加速平台」完整菜单配置，可作为新产品的复制起点 |
| 面板预设 | `presets/productNav.tsx` | 面板 5 栏全部产品/分组/服务（`CALSPEED_PRODUCT_NAV`） |

**刻意不做的事**

- 不依赖 `react-router`：跳转统一走 `onNavigate(path)` 回调，由页面注入。
- 不含任何产品业务数据：菜单、品牌、租户、用户名全部由 props / preset 传入。
- 不改动原页面 DOM 结构与间距：点击区域多为 `<span>`（仅收起为 `<button>`），以保证像素还原。

## 3. 最小接入示例

```tsx
// src/pages/<产品>/<需求>/<页面>/_shared.tsx
import { useNavigate } from 'react-router-dom'
import { PlatformHeader, SideNav } from '@/lib/platform-shell'

const ROWS = [
  { kind: 'item', label: '总览', icon: 'overview', lvl: 1 },
  { kind: 'section', label: '知识库' },
  { kind: 'sub', label: '我的知识库', icon: 'book', lvl: 2, active: true },
] as const

export function AppHeader() {
  return <PlatformHeader productName="智能应用" consoleLabel={false} userName="张虎测试" accountName="admin" />
}

export function AppNav() {
  const navigate = useNavigate()
  return (
    <SideNav
      rows={[...ROWS]}
      menuTitle="知识服务"
      tenant={{ node: '长沙…', workspace: 'zhan…' }}
      onNavigate={navigate}
    />
  )
}
```

页面里按原来的方式使用：

```tsx
<div className="flex min-h-screen flex-col bg-[#f5f6f8]">
  <AppHeader />
  <div className="flex flex-1 overflow-hidden">
    <AppNav />
    <main className="flex-1 overflow-y-auto">{/* 页面内容 */}</main>
  </div>
</div>
```

## 4. 更省事的做法：复制预设

新产品的菜单往往有十几二十条，逐条写 `rows` 很啰嗦。直接复制 `presets/calspeed.tsx`：

1. 新建 `src/lib/platform-shell/presets/<你的产品>.tsx`；
2. 复制 `CALSPEED_SHELL` 整体，改 `productName` / `tenant` / `menuTitle` / `rows`；
3. 把 `rows(activeKey)` 里不用的条目删掉，路径改成真实路由；
4. 在页面 `_shared.tsx` 里引用这个 preset。

`rows` 是**函数**而不是常量，因为选中态、展开/收起箭头要随 `activeKey` 变化：

```tsx
rows: (activeKey = '我的知识库'): ShellNavRow[] => [
  { kind: 'sub', label: '我的知识库', icon: 'book', lvl: 2, active: activeKey === '我的知识库' },
  { kind: 'group', label: '知识加工', icon: 'layers', lvl: 2,
    chevron: activeKey === '知识加工' ? 'up' : 'down' },
  { kind: 'sub', label: '文档解析', icon: 'hdd', lvl: 3, active: activeKey === '文档解析' },
]
```

### `ShellNavRow` 四种行型

| `kind` | 用途 | 关键字段 |
| --- | --- | --- |
| `section` | 分组小标题（灰字、无图标） | `label` |
| `item` | 一级可点击条目 | `label` `icon` `lvl: 1` `path?` `onClick?` |
| `group` | 可展开的父级（带上下箭头） | `label` `icon` `lvl: 2` `chevron: 'up' \| 'down'` |
| `sub` | 子级条目（二/三级） | `label` `icon` `lvl: 2 \| 3` `active?` `path?` |

- `path`：给了就交给 `onNavigate(path)`；也可直接给 `onClick`。
- `active`：由 preset 根据 `activeKey` 算好，组件内部不再猜。
- 组件不读路由、也不猜选中态：`active` 必须由 preset 显式给，否则该项渲染为未选中。

## 5. 换品牌色

```css
/* src/index.css */
:root { --shell-accent: #166eff; }        /* 算力加速平台：蓝 */
:root { --shell-accent: hsl(243 75% 59%); } /* 智能应用：紫蓝 */
```

如需按页面覆盖，给外层容器加行内 CSS 变量即可（这是唯一允许的行内样式场景）：

```tsx
<div style={{ ['--shell-accent' as string]: 'hsl(243 75% 59%)' }}>
```

## 9. 注意

- 这份素材对应的是**在线服务**那套外壳（自绘 SVG 图标、`#166EFF`），
  不是 `弹性扩缩容/推理服务` 的 lucide 图标外壳，两者不要混用。
- `SideNav` 内部有 `overflow-y-auto`，父容器需给确定高度（`h-screen` 或 `flex-1` + `overflow-hidden`），否则侧栏会撑高整页。
- 顶栏/侧栏是「页面级」的，不做成全局 Layout：不同产品的外壳差异只通过 preset 表达。
