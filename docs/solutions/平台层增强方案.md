# 平台层增强方案（7 项）

> 决策留痕: 2026-08 平台层(外壳 Host)增强批。涉及 `src/host/`、`src/App.tsx`(R1 红线范围, 经项目负责人明确要求执行)。

## 背景
平台层存在 7 个改进点: 搜索半成品未接入 / 根路径直接重定向无总览 / 契约校验无流水线 / 版本切换无变更总览 / PRD 无目录 / 设计系统切换对硬编码色页面无提示 / meta.json 字段不足。

## 实施清单

| # | 功能 | 方案要点 | 涉及文件 | 状态 |
|---|------|---------|---------|------|
| 1 | 搜索接入 | 复用既有 SearchPanel + useSearch(fuse.js), Sidebar 搜索入口 + Cmd+K/Ctrl+K 全局快捷键 | `AppLayout.tsx` `Sidebar.tsx` | 已实施 |
| 2 | 平台首页总览 | 根路径 `/` 渲染 Overview(统计条 + 模块卡片 + 页面清单), 替代重定向 | `App.tsx` `host/components/Overview.tsx`(新) | 已实施 |
| 3 | 契约校验流水化 | `scripts/validate-all.js` 遍历 src/pages 逐页调用 validate-page.js 并汇总; npm scripts `validate` / `validate:all`; **顺带修复**: Figma 来源页面(`meta.source="figma"`)inline style 降级为 warn(与 page-generator §4.0 对齐), 修正 ANSI 色码下汇总正则失效 | `scripts/validate-all.js`(新) `scripts/validate-page.js` `package.json` | 已实施 |
| 4 | 版本变更总览 | PageView 新增「变更」视图: 优先 meta.versionSummary.features, 兜底从 PRD 自动提取 **FR-X; 合并 versionSummary 中 PRD 未覆盖条目(如 F-Copilot); A/B/M/R 类型徽标 | `PageView.tsx` `meta.json(智能诊断版)` | 已实施 |
| 5 | PRD 阅读增强 | 左侧 TOC 目录(2-4 级标题, slugify 锚点, 平滑滚动), h1-h6 注入锚点 id | `PageView.tsx` | 已实施 |
| 6 | 设计系统切换落地 | meta.designSystem 声明目标设计系统; 切换器显示「页面匹配」徽标 + 未声明提示, 避免切换无变化误解 | `DesignSystemSwitcher.tsx` 5 个页面 meta.json | 已实施 |
| 7 | 页面元数据扩展 | PageMeta 新增 source/designSystem/owner/status/updatedAt/description/versionSummary; 5 个页面 meta.json 补齐 | `pageRegistry.ts` 5 个 meta.json | 已实施 |

## 影响范围
- `src/host/`: AppLayout / Sidebar / PageView / DesignSystemSwitcher / Overview(新) / pageRegistry
- `src/App.tsx`: 根路径改为总览页
- `scripts/`: validate-all.js(新) / validate-page.js
- `src/pages/*/meta.json`: 全部 5 个页面补齐扩展字段
- 误改恢复: `git checkout -- src/host/ src/App.tsx src/main.tsx`
