## 1. 国际厂商

### 1.1 Datadog Bits AI SRE（业界最前沿，2025.12 GA）

Datadog 是当前 AIOps 平台 Forrester Wave 2025 Q2 Leader。Bits AI 演进：2023 聊天机器人 → 2024 自主调查预览 → 2025 GA。核心设计：

- **假设驱动调查（假设树）**：Agent 模仿人类 SRE——先收集上下文（监控器消息、关联 runbook、同监控器历史调查、环境探索查询），再形成多个假设，用针对性查询逐一**验证/排除**，有证据分支深挖、无证据剪枝。核心哲学：**关注告警与假设相关遥测的因果关系，而不是把数据全吞进来**。复杂假设递归拆子假设，并行探索。
- **自动调查（Auto-Investigate）**：监控器进入告警态即自动开始调查，也可手动触发；结果带证据引用推送到 Slack/Teams/移动端/On-Call/Case Management。
- **Agent Trace**：每一步工具调用、查了什么数据、中间分析全部摊开给人看——可审计性建立信任。
- **对话内 triage 动作（需人工确认）**：发 Slack/Teams 消息、建事故、呼叫工程师、建 case、开 Jira 票共 7 种动作，全部要人确认；基础设施操作（重启/清缓存/隔离）过 RBAC + Audit Trail。
- **记忆与反馈**：从历史告警学习，接受人类反馈修正/强化结论。
- **bits.md**：团队把自己的排障知识以 Markdown 写入配置，Agent 调查时参考（SRE 版 CLAUDE.md），知识可版本化/评审/继承。
- **假设树引擎 + 领域模型**：`Toto` 时序基础模型做异常预测，通用大模型做根因叙事与假设推理，各司其职。
- **评估体系**：数千起标注过真实事故做回归门禁（评估集=真实事故+真实遥测+人类标注）。
- **定价**：按"得出结论的调查"计费（AI Credits），无结论不收钱。

### 1.2 Dynatrace Davis AI（确定性因果 AI）

- 基于 Smartscape 拓扑 + Grail 数据湖，走**确定性因果 AI** 路线：自动做根因分析，可解释性强。
- 与 Datadog 的差异：Davis 更偏"规则+因果图"确定性推理，Bits 更偏 LLM 假设推理。

### 1.3 Moogsoft / PagerDuty（事件管理与告警关联）

- **事件聚类（Event Clustering）**：将潜在关联的告警自动归并为逻辑一致的"噪声组"，减少同一事件连续告警，聚焦真正根源。
- PagerDuty SRE Agent 卡位独特：直接坐在升级策略上（告警 → 分级升级 → 通知值班）。

### 1.4 云智慧 Castrel AI（国内对标）

- 同样采用"假设驱动"调查范式，定位 AI SRE 从数据摘要迈向因果推理的新阶段。

## 2. 国内大厂实践

- **字节跳动**：智能运维 AI Agent 采用"控制端（感知端、行动端）"架构，覆盖故障排查、知识咨询场景；声称故障自愈率提升至 85%、人工干预减少 70%（厂商自报）。
- **华为**：大小模型协同的网络智能运维（大模型做语义理解，小模型做检测/推理）。
- **蚂蚁**：AIEvo 等 Agent 平台支持告警诊断场景多智能体协作（本原型 Agent 架构调研已引用）。
- **阿里云 SLS**：内置智能时序算法（变点检测、异常预测、根因分析）+ 智能巡检。

## 3. AIOps 工程实践通用能力

### 3.1 核心算法链（业界共识）

```
数据层（指标/日志/链路/事件/变更）→ 算法层（告警降噪聚类 → 异常检测 → 根因定位）→ 行动层（自动响应 / 智能通知 / Runbook 执行）
```

- **告警聚类/降噪**：基于时间窗口（5 分钟）+ 拓扑关联，200 条告警可压缩为 1 个故障事件；有效告警比例 25% → 80%+。
- **动态基线异常检测**：STL 分解（趋势/周期/残差）+ 3-Sigma，比静态阈值误报率降 60%+。
- **因果推理**：PC 算法 + CMDB 拓扑约束缩小根因搜索空间。
- **分级自动化**：先只读推荐 → 低风险动作自动化（通知/记录）→ 高危动作人工确认（重启/扩缩容）。

### 3.2 事件管理闭环（ITIL 4 + AI）

- **故障知识库**：历史经验沉淀可检索，复用率可达 70%。
- **常规修复自动化**：覆盖 60% 以上已知故障场景（预编排 Runbook）。
- **故障复盘**：持续改进、分享知识、沉淀经验（本原型「故障报告撰写规范」skill 即对应此能力）。
