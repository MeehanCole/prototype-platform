## 2026-08-07 Artifact 侧边面板（工具产物独立展示）
- 背景：业界 AI 客户端（Claude Artifacts / ChatGPT Canvas / WorkBuddy 制品等）普遍把 AI 产物从「消息内嵌」挪到「独立面板」展示；本平台工具卡片已产出 metric/trace/flame 三类 SVG 可视化（指标趋势 / SkyWalking 链路拓扑 / 火焰图），但内嵌在消息里空间受限，需支持点击后左侧弹出面板沉浸查看
- 调研结论（业界三类模式）：
  - **Artifact 侧边面板**（Claude）：产物按类型（Markdown/HTML/SVG/Mermaid/React）在对话旁独立面板渲染，聊天只留紧凑引用卡片，支持版本管理与就地迭代
  - **工具调用驱动 Artifact**（Vercel AI SDK / ai-client）：产物由 agent 内置 `manage_artifact` 工具在对话流产出，`tool-call → tool-result → done` 后面板自动打开，产物内嵌消息 `toolResults` 随会话持久化
  - **Canvas-first 工作台**（Agent Studio / WorkBuddy）：聊天收窄为侧栏驱动工作，产物全部打开到画布多开 tab，对话留「打开到画布 →」入口（present_files 统一入口）
- 候选方案：A Artifact 侧边面板（推荐，点击工具卡片「在面板打开」→ 左侧弹出独立面板，支持日志全文/链路大图/监控大图/原始 JSON，多产物切换 + 最大化 + 导出）／B 内联展开增强（保持消息内展开，仅扩大展开区，改动最小但大图空间仍受限）／C Canvas 画布工作台（左侧画布 + 右侧对话，信息密度最高但需重构抽屉布局，超出当前诊断场景）
- 选定方案：A（待用户最终确认）——实现上采用 `artifactRegistry` 注册表复用现有 metric/trace/flame 渲染器，MVP 范围：仅「点击工具卡片 → 左侧面板展示 + 多产物切换」，不做自动弹出、不做版本管理；改动集中在 `DiagnosisDialog.tsx` 内，不动共享壳
- 影响范围：`DiagnosisDialog.tsx`（新增 ArtifactPanel + 注册表，工具卡片加「在面板打开」入口）
- 结论状态：已调研（推荐 A，待用户确认后实施）

## 2026-08-10 故障知识库重新评估：knowledge-base 落地为历史诊断检索（不引入 RAG/向量库）
- 背景：重新讨论「故障知识库」——用户明确不引入 RAG（需向量数据库）；存储底座仅 PG + ES；参考 OpenKB/PageIndex「无向量、知识编译、推理导航」理念
- 调研结论：
  - 运维检索"零容忍"：错误码（OOMKilled/502.14）/服务/命令必须精确命中 → BM25/keyword 是主力，向量检索对精确字符串"脸盲"，业界运维知识库普遍采用多路召回中 BM25 保精度
  - 知识库写入通行「分级审核制」：提交=草稿、审核=发布、**未发布不被索引**（"知识影响力始于被索引那一刻"），否则出现同一问题多份冲突文档的"知识垃圾场"
- 讨论演进：完整方案（PG 事实源 + ES 检索镜像 + OpenKB 式知识编译 + 四角色审核 + 双层库）→ 用户判定「太复杂，平台不需要」→ 质疑「知识库到底需不需要？skill 是否就够？」
- 结论判定：
  - **独立故障知识库原型阶段不做**（维持 2026-08-07 D 方案）——无真实故障数据时知识库为空，价值无法体现；skill（预置方法）+ 诊断历史（20 条可还原/导出）已覆盖核心诉求
  - 知识库价值仅在特定条件兑现：同类型故障反复出现 / 环境项目特有经验 / 团队大人员流动——现阶段均不满足
- 选定方案：**knowledge-base 技能落地为「检索历史诊断记录」**（零新存储 / 零权限复杂度 / 无向量）——Agent 诊断时调用，按告警策略（指纹）+ 监控目标 + 关键词匹配本地历史；命中则列为候选假设
- 关键原则：**历史记录是「参考」不是「答案」**——命中后三步处理：① 作为候选假设带入诊断 ② 用当前实时数据验证（验证通过才采纳，否则排除）③ 结论引用历史案例编号可回溯
- 检索到后的处理：命中时消息流插入「相似历史案例」卡片（标题/时间/根因/处置 + 一键「采用验证步骤」）；未命中显示轻量提示且不影响诊断，本次结论照常保存（沉淀供后续复用）
- 影响范围：`DiagnosisDialog.tsx`（知识库查询卡片 + 相似历史案例卡片 + 采用验证步骤，历史匹配走现有 localStorage 诊断历史 + 内置演示案例）
- 结论状态：已实施（原型演示）
