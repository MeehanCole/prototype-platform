# 平台导航面板 1:1 还原方案（已与实现同步）

> 目标：将原型中的平台级导航面板还原为与真实平台一致的外观与交互。
> 依据：真实平台截图 `docs/IntelligentDiagnosis/assets/existing-product/平台-导航面板.png`（经视觉 MCP qwen3-vl-plus 识别）。
> 状态：**已实现**，本文档与 `src/pages/AIOps/IntelligentDiagnosis/_shared.tsx` 当前代码一致。

## 1. 真实平台调研结论

### 1.1 顶部栏（Header，56px 白底，底部 1px 边框）

| 顺序 | 元素 | 说明 |

| 1 | **12宫格图标按钮**（3×3 网格） | 32×32px，距左 16px，灰色 `#606266`，hover 变主色 `#409EFF`。**核心入口：点击弹出平铺导航弹窗** |

| 4 | 右侧操作区 | 帮助文档、工单、加入蓝信群、系统租户、用户头像下拉（admin） |

### 1.2 平台导航交互（关键发现）

- **平铺弹窗**：点击顶部栏左侧 12宫格图标后，从**左上角**弹出多分类平铺弹窗（非常驻侧边栏、非左侧抽屉）
- **分类横向平铺**：所有一级分类**并排成多列**，每列内菜单项**纵向排列**（一级分类 → 二级分类 → 菜单项，三级结构）
- **AIOps 不着色**：智能中心/AIOps管理 与其它分类一致，**纯文字排序**，不做着色加重
- **与原型内导航互不影响**：原型内左侧常驻 AIOps 导航栏保留，与平台导航弹窗互相独立

## 2. 当前实现（与代码一致）

导航还原集中在 `_shared.tsx`，由 4 个组件组成：

| 组件 | 实现 |
|------|------|
| `PlatformShell` | 持有 `navOpen` 状态，组合 Header + 常驻 Sidebar + 内容区 + 平铺弹窗 |
| `PlatformHeader` | 56px 白底顶部栏，左侧 **12宫格图标**（`LayoutGrid` 18px，32×32 按钮）触发 `onOpenNav` |
| `PlatformSidebar` | **常驻 200px** 左侧导航：智能中心 → AIOps管理 → 3 个子页面（模型/工具/技能管理，对话统一走应用面常驻入口），激活项蓝色高亮（蓝字 + 浅蓝底 + 左侧 2px 蓝条），切换原型内部页面 |
| `PlatformNavModal` | **左上角平铺弹窗**（新增组件），承载完整平台导航 |

### 2.1 平铺弹窗关键样式

- **定位**：`fixed left-0 top-0 z-50`（**顶部顶着页面**，覆盖 Header；左上角展开）
- **遮罩**：`fixed inset-0 z-50 bg-[rgba(0,0,0,0.3)]`，点击遮罩关闭
- **头部**：`LayoutGrid` 图标 + "平台导航" 标题 + X 关闭按钮
- **内容布局**：`grid grid-cols-4`，`gap-x-[16px] gap-y-[12px]`，内边距 `p-[12px]`，超高滚动 `max-h-[calc(100vh-140px)]`
- **分类列**：固定等宽 `w-[140px]`（保证跨行严格对齐），标题 13px 加粗带下边框，菜单项 12px `px-[6px] py-[3px]`
- **排列效果**：共 9 个一级分类（8 真实 + 智能中心），4 列换行 → 第 1 行（智算服务/容器云/CICD/中间件）、第 2 行（平台巡检/运维中心/**交付中心/运营中心**，逐列对齐其上 CICD/中间件）、第 3 行（智能中心）

### 2.2 弹窗内菜单行为

- **智能中心（AIOps管理）5 项**：可点击切换原型页面，点击后 `onPageChange` + 关闭弹窗
- **激活项**：保持**纯文字** `text-[#606266]`，**不变蓝、无蓝色背景框**（与其它菜单一致，符合"不着色"要求）
- **其它可点击项**：hover 变蓝 `#409EFF` + 浅蓝背景（仅悬停反馈）
- **非 AIOps 菜单**：`disabled` 纯静态展示，`cursor-default`，不可点击

## 3. 交互设计

### 3.1 状态机

```
默认态：导航弹窗收起，常驻 AIOps 侧边栏可见
   │
   ▼ 点击顶部栏 12宫格图标
展开态：左上角弹出平铺弹窗 + 半透明遮罩（z-50）
   │
   ├─ 点击 12宫格图标 → 重新展开
   ├─ 点击智能中心菜单项 → 切换原型页面并关闭弹窗
   ├─ 点击遮罩 / 右上角 X → 关闭
   └─ 按 Esc → 关闭
```

### 3.2 交互细节

- **12宫格图标**：顶部栏最左侧，32×32px，`LayoutGrid`（lucide），默认灰色 `#606266`，hover 变主色 `#409EFF` + 浅蓝背景，带 `title="平台导航"` 提示
- **弹窗打开/关闭**：无动画即时显示（遮罩淡入非必需），Esc 键支持关闭
- **菜单选中态**：弹窗内**无**选中高亮（纯文字）；常驻侧边栏保留蓝色高亮作为页面定位
- **常驻侧边栏**：200px，仅智能中心/AIOps管理 分类，与弹窗完全独立

### 3.3 数据模型

```ts
// _shared.tsx PLATFORM_NAV：一级分类 → 二级分类 → 菜单项
type NavCategory = {
  title: string                                    // 一级分类，如 '智算服务'
  groups: { title?: string; items: string[] }[]    // 二级分类（可选）+ 菜单项
}

// 弹窗运行时追加"智能中心"分类：
// { title: '智能中心', groups: [{ title: 'AIOps管理', items: AIOPS_PAGES.map(p => p.label) }] }

// 可点击判定：仅 cat.title === '智能中心' 的菜单项绑定原型页面切换（onPageChange）
```

- 非 AIOps 分类菜单为**纯静态展示**（原型范围内无真实页面，`disabled` 不可点）
- 智能中心分类下 5 项绑定原型内部页面切换（`onPageChange`），切换后关闭弹窗
