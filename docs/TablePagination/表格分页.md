# 表格分页素材 · TablePagination

> 一行式的表格底部分页：`共 N 条 · 每页条数 · ‹ 页码 ›`。
> 视觉已与设计稿 1:1 对齐（控件统一 35px 高、2px 圆角），页面差异只走 props。
>
> 源码：[`src/lib/table-pagination/`](../../src/lib/table-pagination/)
> 真实使用方：数据集管理（`src/pages/算力加速平台/数据管理/数据集管理`）

---

## 1. 组成

```
共 5 条        [ 12 条/页 ▾ ]   [‹]  [1]  [2]  [›]
└ 总数 ─┘       └ 条数选择 ┘     └── 翻页 + 页码 ──┘
```

| 部位 | 规格 |
| --- | --- |
| 总数文案 | 13px / `#656565` / 行高 1 |
| 每页条数 | 94×35，白底，1px `#DCDFE6` 描边，2px 圆角，右侧 14px 下拉箭头 `#8A8F99` |
| 翻页按钮 | 35×35，`#F5F5F5` 实心（**无描边**），2px 圆角，图标 `#595959` |
| 当前页 | 35×35，品牌色实心（`--shell-accent`）+ 白字 |
| 其他页码 | 同翻页按钮样式，`min-width 35px`，两位数自动加宽 |
| 省略号 | 15×35，文字 `#8A8F99` |
| 元素间距 | 总数 ↔ 分页组 25px；组内各控件 10px |
| 禁用态 | 背景仍 `#F5F5F5`，图标 `#C9CDD4`，`not-allowed` |

## 2. 页码折叠规则

`totalPages ≤ 7` 全部平铺；超过 7 页时首尾常驻、当前页左右各留 1 页，其余折叠为 `…`：

```
当前 1  / 20 → 1 2 … 20
当前 6  / 20 → 1 … 5 6 7 … 20
当前 20 / 20 → 1 … 19 20
```

折叠逻辑导出为纯函数 `pageWindow(page, totalPages)`，可单测、可在别处复用。

## 3. 最小接入

```tsx
import { TablePagination } from '@/lib/table-pagination'

const [page, setPage] = useState(1)
const [pageSize, setPageSize] = useState(10)

<TablePagination
  total={filtered.length}
  page={page}
  pageSize={pageSize}
  onChange={({ page: nextPage, pageSize: nextSize }) => {
    setPageSize(nextSize)
    setPage(nextPage)
  }}
/>
```

`onChange` 同时带出 `page` 与 `pageSize`，不需要调用方自己判断「是翻页还是改条数」——
改条数时组件内部已经把它折算成 `page: 1`。

## 4. Props

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `total` | `number` | — | 总条数（过滤后） |
| `page` | `number` | — | 当前页，从 1 开始；越界自动收敛 |
| `pageSize` | `number` | — | 每页条数 |
| `pageSizeOptions` | `number[]` | `[10, 20, 50]` | 条数可选项 |
| `onChange` | `({page, pageSize}) => void` | — | 翻页或改条数 |
| `renderTotal` | `(total) => ReactNode` | `共 N 条` | 自定义总数文案（可放「共 N 条，已选 M 条」） |
| `renderPageSize` | `(size) => ReactNode` | `N 条/页` | 自定义条数文案 |
| `showPageSize` | `boolean` | `true` | 隐藏条数选择器（移动端窄屏） |
| `extra` | `ReactNode` | — | 右侧插槽，会自动 `ml-auto` 推到最右 |
| `className` | `string` | `''` | 外层类名，控制外边距与对齐 |

## 5. 换品牌色

当前页与条数选择器的聚焦描边都取 `var(--shell-accent, #166eff)`，与平台外壳同源：

```css
/* src/index.css */
:root { --shell-accent: #166eff; }
```

只改这一处，分页与顶栏/侧栏的品牌色一起变。中性色（`#F5F5F5` / `#DCDFE6` / 文字灰）是固定值，不随主题走，
避免换色后分页块与表格底色打架。

## 6. 注意事项

- 组件不含任何业务文案与路由，`total` 由页面传入过滤后的数量；
- 无数据时不建议渲染（页面自己判断 `total > 0`），组件本身不产出空态；
- 宽度不足时外层 `flex-wrap` 会把分页组换行，不会出现横向滚动；
- 不要在页面里复制这段 JSX —— 复制即视为 Tech Debt，下次改样式必漏。
