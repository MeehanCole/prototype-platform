## 工作流

1. **B1 输入采集**：用户提供现有产品截图 → 存放 `assets/existing-product/`
2. **B2 视觉还原**：分析设计 token（主色/圆角/字号/间距），与用户确认风格后生成原型（85%+ 像素精度）
3. **B3 规范适配**：适配页面契约（meta.json / prd.md / feature-tags）
4. **B4 平台接入**：注册路由（目录名小写）、导航
5. **C2-C5**：新需求（在线服务优化）分析、方案设计、原型改造、反向 PRD + 功能点标注
