# 算力加速平台 · 方案纪要

## 2026-11-24 · 方案 v1：租户配额素材化并从协作台导航隐藏

- **问题**：「租户配额」页面里的集群资源配额卡片与四列表格是典型可复用 UI，但目前实现耦合在租户业务页面中；同时用户要求该页面不再出现在协作台导航。
- **候选方案**：
  1. 把整页登记进素材库：改动小，但预览会混入业务外壳和路由，不能作为干净素材复用。
  2. 抽取集群卡片 / 表格 / 刷新编辑入口到 `src/lib/resource-quota`，页面保留业务状态与弹窗，素材库用真实组件做实时预览。
  3. 直接删除租户配额页面与路由：会破坏直接访问，不满足「隐藏导航」的最小变更诉求。
- **结论**：选择方案 2。租户配额页作为真实使用方，继续保留直接路由；通过 `meta.hidden: true` 从产品树 / 侧栏 / `Cmd+K` 搜索中隐藏，不修改 Host。
- **影响面**：
  - 新增 `src/lib/resource-quota/`（组件实现与 barrel）。
  - 新增 `docs/ResourceQuota/资源配额素材.md`，并在开发态素材库登记 `resource-quota`。
  - 修改 `src/pages/算力加速平台/租户管理/租户配额/` 下的页面、PRD、功能点与 `meta.json`。
- **状态**：已实施，等待静态校验与浏览器验收。
