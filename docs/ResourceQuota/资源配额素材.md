# 资源配额卡片素材

## 1. 解决什么问题

租户配额、项目配额等页面都会用「集群 / 资源分组卡片 + 资源类型 / 已使用 / 配额 / 余量」表格展示资源上限。
`src/lib/resource-quota` 把这块稳定视觉抽成 props 驱动的展示组件：业务只准备数据和回调，不再复制表格样式、单位格式化、不限制形态与 80% 用量告警。

## 2. 组成

| 导出 | 作用 |
| --- | --- |
| `ResourceQuotaBoard` | 页面级展示：标题、说明、分组标题、刷新按钮、多个集群卡片 |
| `ResourceQuotaClusterCard` | 单个集群卡片：标题、编辑按钮、四列表格 |
| `ResourceQuotaCluster` | 集群数据结构：id / name / code / rows |
| `ResourceQuotaRow` | 表格行数据结构：key / label / kind / used / quota / icon |

组件不依赖路由、全局 store、业务路径或后台接口；外壳、编辑弹窗、Mock 数据都属于调用方职责。

## 3. 视觉规则

- 页面标题：28px / 700 / `#323232`，说明文字 14px / `#AAAAAA`。
- 分组标题：16px / 700 / `#1D2129`，右侧 32×32 刷新按钮。
- 集群卡片：白底、1px `#E5E6EB` 描边、2px 圆角；卡片之间 16px 间距。
- 卡片头：15px 粗体集群名，灰色英文标识，右侧蓝色「编辑配额」按钮。
- 表头：`#F7F8FA` 底，13px / `#4E5969`；列宽 34% / 22% / 22% / 22%。
- 表格行：13px / `#1D2129`，虚线分隔；`CPU 限制` / `内存限制` 带图标，请求行留空对齐。
- 不限制：`quota: null` 时「已使用」显示 `-`，「配额」「余量」显示「不限制」。
- 使用率：`quota > 0` 且 `used / quota >= 80%` 时，已使用数字后追加红色百分比标签。
- 默认单位：CPU `核`、内存 `GiB`、存储 `GB`、GPU `卡`；可用 `units` 覆盖。

## 4. 最小接入

```tsx
import {
  ResourceQuotaBoard,
  type ResourceQuotaCluster,
} from '@/lib/resource-quota'

const clusters: ResourceQuotaCluster[] = [
  {
    id: 'cluster-a',
    name: '长沙智算中心',
    code: 'changsha-dc-cluster',
    rows: [
      { key: 'cpuLimit', label: 'CPU 限制', kind: 'cpu', used: 96, quota: 128 },
      { key: 'cpuRequest', label: 'CPU 请求', kind: 'cpu', used: 48, quota: 64 },
      { key: 'memLimit', label: '内存限制', kind: 'mem', used: 320, quota: 512 },
      { key: 'memRequest', label: '内存请求', kind: 'mem', used: 160, quota: 256 },
    ],
  },
]

<ResourceQuotaBoard
  title="资源配额"
  description="用于管理和分配资源使用总量。"
  clusters={clusters}
  onRefresh={() => console.log('refresh')}
  onEdit={(cluster) => console.log(cluster.id)}
/>
```

## 5. 可配置能力

| Prop | 说明 |
| --- | --- |
| `title` / `description` | 页面标题与说明，不传则不渲染 |
| `sectionTitle` / `sectionExtra` | 分组标题与标题右侧插槽（可放 `NewTag`） |
| `clusterLabel` / `editLabel` | 集群标题前缀与编辑按钮文案 |
| `showRefresh` / `showEdit` | 分别控制刷新 / 编辑按钮 |
| `columns` | 覆盖四列表头文案 |
| `units` | 覆盖默认单位映射 |
| `renderIcon` | 自定义行首图标；不传时按 key 中的 `cpu/mem` + `limit` 推断 |
| `onRefresh` / `onEdit` | 刷新与编辑回调 |

## 6. 变更规则

- 视觉改动只改 `src/lib/resource-quota`，并同步本文档；不要改素材库里的预览样式。
- 业务数据回写、弹窗校验、路由跳转不属于本素材职责，保留在调用方页面。
- 新增资源类型时优先通过 `rows` 扩展，不要为单个页面写死行数据。
- 开发态素材库 id：`resource-quota`；页面「租户配额」是真实使用方，但已从协作台导航隐藏。
