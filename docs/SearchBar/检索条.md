# 检索条 · SearchBar

> 一句话：列表页顶部的组合式检索条——输入框 + 后置放大镜 + 刷新按钮；传了 `fields` 就变成「字段下拉 + 输入框 + 放大镜」的带过滤项形态。
> 源码：[SearchBar.tsx](../../src/lib/search-bar/SearchBar.tsx) · 桶文件：[index.ts](../../src/lib/search-bar/index.ts)
> 真实使用方：`数据集管理`（单输入 + 清空）、`在线服务`（字段下拉 + 联动下拉/输入 + 查询/重置）、素材库预览（`/__assets?a=search-bar`）。

## 1. 组成

单输入形态：

```
┌──────────────────────────────┐ ┌────┐
│ 输入名称搜索              │🔍│ │ ↻  │
└──────────────────────────────┘ └────┘
   输入框 222              54      54
```

带过滤项形态：

```
┌────────┬─────────────────────┐ ┌────┐
│ 名称 ▾ │ 请输入              │🔍│ │ ↻  │
└────────┴─────────────────────┘ └────┘
    94            224             54      54
```

| 部位 | 规格 |
| --- | --- |
| 组合框整体 | 外框 `h-8`（32px，含上下各 1px 边框，内容区 30px）、圆角 4px、`1px solid #D9DDE3`、白底 |
| 内部控件 | 下拉 / 输入框 / 放大镜按钮统一 `h-full` 撑满 30px 内容区，不单独设固定高度 |
| 前置字段下拉 | 宽 94px、灰底 `#F5F6F8`、文字 `#4E5969` 14px、左侧圆角 4px；右侧 1px 竖向分隔线同边框色 |
| 下拉箭头 | ChevronDown 12px、`#86909C`，距右 8px |
| 输入框 | 默认宽 222px（可调）、14px、文字 `#1F2329`、placeholder `#86909C` |
| 后置搜索按钮 | 宽 54px、灰底 `#F5F6F8`、左侧 1px 分割线、放大镜 14px `#86909C`、右侧圆角 4px |
| 刷新按钮 | 54×32、白底、`1px solid #D9DDE3`、圆角 4px、RefreshCw 14px `#4E5969` |
| 元素间距 | 10px |
| 聚焦态 | 组合框描边切到 `var(--shell-accent, #166eff)` |
| 卡片外壳 | 不在组件内，由使用方包裹（白底 + `0 2px 8px rgba(0,0,0,.08)` + 12px 内边距） |

## 2. 两种形态

只有一个组件，形态由 `fields` 决定：

- **不传 `fields`** → 单输入形态，输入框左侧自己带 4px 圆角。
- **传 `fields`** → 前置下拉出现，值由 `fieldValue` / `onFieldChange` 控制；未传 `fieldValue` 时取第一项。

交互约定：输入框内 `Enter` 触发 `onSearch`，`Esc` 清空输入；`showClear` 打开时右侧出现清空 X。

第三种用法：`control` 插槽。传了 `control` 就用它替换输入框（如「调用模型名」下拉），组合框外壳、前置字段下拉、放大镜按钮保持不变，适合「字段切换 + 后置控件联动」的场景：

```tsx
<SearchBar
  value={keyword}
  onChange={setKeyword}
  onSearch={query}
  fields={fields}
  fieldValue={field}
  onFieldChange={setField}
  inputWidth={280}
  showRefresh={false}
  control={
    field === 'model' ? (
      <MySelect bare value={model} onChange={setModel} />
    ) : undefined
  }
/>
```

作为 `control` 传入的控件需自行铺满容器（`h-full w-full`）且不带自身边框，边框由组合框提供。

## 3. 最小接入

单输入形态：

```tsx
import { SearchBar } from '@/lib/search-bar'

<SearchBar
  value={keyword}
  onChange={setKeyword}
  onSearch={() => setPage(1)}
  onRefresh={reload}
/>
```

带过滤项形态：

```tsx
<SearchBar
  value={keyword}
  onChange={setKeyword}
  onSearch={() => setPage(1)}
  fields={[
    { label: '名称', value: 'name' },
    { label: '状态', value: 'status' },
  ]}
  fieldValue={field}
  onFieldChange={setField}
  placeholder="请输入"
  onRefresh={reload}
/>
```

## 4. Props

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | 输入框的值（必填） |
| `onChange` | `(v: string) => void` | — | 输入变化（必填） |
| `onSearch` | `() => void` | — | 点放大镜或按 Enter（必填） |
| `fields` | `{ label: string; value: string }[]` | — | 传了才出现前置字段下拉 |
| `fieldValue` | `string` | 第一项 | 当前选中字段 |
| `onFieldChange` | `(v: string) => void` | — | 字段变化 |
| `placeholder` | `string` | `输入名称搜索` | 输入框占位文案 |
| `inputWidth` | `number` | `222` | 输入框 / 自定义控件宽度（px） |
| `fieldWidth` | `number` | `94` | 前置字段下拉宽度（px） |
| `showClear` | `boolean` | `false` | 有内容时在输入框内展示清空 X |
| `onClear` | `() => void` | — | 点清空时回调；不传则只清空本地值 |
| `control` | `ReactNode` | — | 替代输入框的后置控件（如下拉），宽度取 `inputWidth` |
| `showRefresh` | `boolean` | `true` | 是否展示刷新按钮 |
| `onRefresh` | `() => void` | — | 刷新回调 |
| `refreshTitle` | `string` | `刷新` | 刷新按钮 `title` / `aria-label` |
| `aria-label` | `string` | 取 placeholder | 输入框无障碍标签 |
| `extra` | `ReactNode` | — | 右侧插槽（更多筛选等） |
| `className` | `string` | `''` | 外层附加类名（外边距、对齐） |

## 5. 换品牌色

组件里唯一与品牌相关的只有聚焦描边，取值 `var(--shell-accent, #166eff)`；改 `--shell-accent` 即与顶栏/侧栏同步，其余颜色为固定中性色，不随主题变化。

## 6. 注意事项

- **卡片外壳不要做进组件**：截图里的白底 + 阴影 + 内边距属于页面容器，组件只负责一行控件，避免在不同页面里被固定样式绑死。
- 组件内不出现任何业务文案（字段名、placeholder、按钮 title 全部由调用方注入），也不 import `react-router`、不读全局 store。
- 高度固定 32px（`h-8`），与表格分页（35px）等原生工具栏不是同一套规格，不要混用；接入页面时若同排还有 35/40px 按钮，靠外层容器 `items-center` 对齐即可。
- 字段下拉的做法是「透明原生 `<select>` 叠在自绘文字层上方」：各浏览器对 `appearance: none` 的处理不一致（Chromium 仍会画原生箭头），所以展示文字与箭头由组件自绘，`<select>` 只负责交互与无障碍。无额外依赖；若后续需要搜索型下拉再单独抽组件。
- 页面之间禁止复制这段 JSX，统一 `import { SearchBar } from '@/lib/search-bar'`。
