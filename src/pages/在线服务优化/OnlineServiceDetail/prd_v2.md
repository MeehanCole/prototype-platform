# 在线服务优化 · 总 PRD（v2 术语统一 + 页面重构 + 表单联动版）

## 0. 文档信息

| 项 | 内容 |
| --- | --- |

## 1. 业务背景与目标

算力加速平台通过 vLLM 部署「推理实例」（负责 GPU 资源调度与进程生命周期），通过 Higress 网关将推理实例包装发布为对外暴露 API 的「在线服务」。现有版本（v1）存在概念与命名混用（如把在线服务本身叫做“策略名称”、把 API 请求体的 `model` 参数叫做“模型名称”需手敲、把后端关联对象在“推理服务”与“推理实例”之间来回切换），且列表页采用 11 列宽表格需横向滚动、顶部筛选卡片占用空间大。

v2 版本对「在线服务」整个模块进行三页联动优化：
- **术语全链路统一**（列表 / 创建 / 编辑 / 详情口径一致）；
- **列表页**由宽表格重构为高信息密度服务卡片列表，并将筛选优化为顶栏组合筛选器；
- **创建/编辑页**补充关联模型自动填充、流量分发策略与灰度发布联动；
- **详情页**将基础配置信息上移至常驻概览卡，【服务配置】Tab 纯策略化。

## 2. 全链路术语统一（跨页基础规则）

| 旧术语 | 新术语 | 适用范围 |
| --- | --- | --- |
| 策略名称 | 服务名称 | 列表筛选/表头、创建/编辑表单项、详情页标题 |
| 模型名称 | 调用模型名 | 列表表头、创建/编辑表单项、详情页、API 文档 `model` 字段 |
| 后端服务类型（内部/外部推理服务） | 后端推理类型（内部/外部推理实例） | 列表单元格、创建/编辑单选、Fallback 类型下拉、详情页 |
| 后端服务实例 | 后端推理实例 | 列表表头、创建/编辑标签、详情页 |

API 文档中 `model` 字段统一取「调用模型名」；「关联模型」仅用于公开发布 + 内部推理实例场景，与「调用模型名（对外暴露别名）」区分。

## 3. 列表页功能需求（OnlineService）

**FR-1 页面整体重新设计**（Must）：
- **列表由表格重构为卡片列表视图**：移除 v1 需横向滚动的 11 列宽表格，改为响应式服务卡片网格（`ServiceCard`），单张卡片聚合：
  - 卡片头部：服务名称（点击进详情）、发布状态标签（已发布/未发布）、发布范围标签（私有发布/模型广场）；
  - 调用模型名与接入地址（未发布显示 `–`），均提供一键复制；
  - 后端推理实例与路由权重可视化：后端推理类型、路由策略（默认路由/按权重分发/金丝雀发布/蓝绿发布）、实例健康状态 Tooltip；逐行展示实例健康圆点、实例名、模型名及流量权重进度条（蓝绿发布展示「当前生效/待命」）；
  - 高可用与安全策略标签：⚡缓存加速、🛡 Fallback（仅常规路由/单实例展示，灰度发布自动隐藏）、⏱ 限流 RPM；
  - 底部监控指标（调用/失败/Token）与快捷操作（编辑、发布/停止发布、删除）。
- **顶部过滤条件优化（组合筛选器）**：移除 v1 独立占行三框并列的搜索卡片，合入列表顶栏右侧；前置筛选字段下拉（服务名称/调用模型名/发布类型）+ 后置联动控件一体化组合框，支持回车/点击查询与一键重置。

**FR-2 创建与行操作**（Must）：左上角「创建在线服务」跳转创建页；点击卡片标题跳转详情页；卡片操作支持编辑、发布、停止发布、删除。

**FR-3 路由策略升级与灰度发布**（Must）：卡片直观展示「按权重分发/金丝雀发布/蓝绿发布」策略类型与实例流量状态；常规路由/单实例服务展示 Fallback 标签，灰度发布服务无 Fallback。

## 4. 创建/编辑页功能需求（OnlineServiceCreate）

**FR-1 服务名称统一**（Must）：表单第 1 项由「策略名称」改为「服务名称」，占位「请输入服务名称」。

**FR-2 后端推理类型与选项优化**（Must）：「后端服务类型」改为「后端推理类型」，选项由「内部推理服务/外部推理服务」改为「内部推理实例/外部推理实例」。

**FR-3 公开发布与关联模型**（Must）：仅「公开发布」+「内部推理实例」时展示「关联模型」下拉（初次切换默认未选，占位「请选择关联模型」）；选关联模型后「调用模型名」自动填充该关联模型名；「后端推理实例」下拉按关联模型过滤（仅展示同模型实例，已选不匹配实例自动清除，无匹配时展示空态提示）。

**FR-4 后端推理实例统一**（Must）：必填多选下拉标签统一为「后端推理实例」，占位「请选择后端推理实例」，下拉项展示实例名、所属模型与运行状态（运行中/已关机）；关联模型过滤场景下仅展示匹配实例并提供空态提示。

**FR-5 调用模型名统一与自动填充**（Must）：「模型名称」改为「调用模型名」。填充规则：① 公开发布且已关联模型时自动填充关联模型名；② 私有发布或未关联模型时按所选第一个后端推理实例模型名自动填充（清空实例自动清空）；③ 自动填充均可被用户手动修改作为对外暴露别名。对应详情【API 文档】`model` 字段。

**FR-6 路由策略升级支持灰度发布与模型Fallback联动**（Must）：「路由策略」升级为「流量分发策略」，采用与缓存加速/全局限流一致的开关控件。
- **与实例数量联动**：选 0/1 个实例时非必选（无红色 *），开关可自由开关（默认关）；选 ≥2 个实例时升级为必选项（红 *），开关自动开启并置灰锁定不可关闭，提示「选择多个后端推理实例时，必须配置流量分发策略」。
- **常规路由（按权重分发）**：默认选中，保持原交互（按权重分发 + 实例 Stepper 权重配置及 100% 校验）；手动增删实例时自动按最新数量均分 100%（编辑态首次进入保留已保存权重，仅手动增删后重新均分）。
- **灰度发布（金丝雀/蓝绿）**：卡片顶部下拉单选「金丝雀发布」或「蓝绿发布」，固定两实例走各自百分比，不区分角色：① 金丝雀两实例对等，改任一百分比另一自动互补为 `100% - 当前值`，提示「两实例权重自动互补（权重之和：100%）」；② 蓝绿发布采用 Active/Standby 单选模型（参考阿里云 MSE、AWS）：用两行可点击单选卡片指定当前承载 100% 流量的实例（选中高亮 + 单选圆点 + 「当前生效 (100%)」绿色徽章，另一「待命 (0%)」灰色徽章），点击即秒级切换，提示「选中实例承载 100% 流量，另一实例不接收流量（0%）」。**仅当选中恰好 2 个实例时灰度发布单选可用**；实例数 0/1/≥3 时置灰禁用并提示「（灰度发布需选择 2 个后端推理实例）」；已选灰度发布后实例数变为非 2 时自动回退为「常规路由策略」。
- **后端推理实例可用性约束**：下拉中「已关机」实例整行置灰禁用（`cursor-not-allowed`），显示「已关机（不可选）」，不可参与路由；仅「运行中」实例可被选入流量分发策略。
- **高可用与安全·模型Fallback联动**：常规路由策略（或单实例未开启流量分发）下保留「模型Fallback」兜底配置（支持内部/外部推理实例及运行中兜底实例）；切换为「灰度发布策略」时隐藏并自动关闭「模型Fallback」。保留全局限流（RPM）及请求超时时间配置。

## 5. 详情页功能需求（OnlineServiceDetail）

**FR-1 服务名称统一**（Must）：面包屑固定为「在线服务详情」；服务名称作为顶部概览卡标题行展示，【服务配置】Tab 不再保留冗余「服务名称」key-value 行。

**FR-2 调用模型名统一**（Must）：顶部概览卡以「调用模型名」字段展示当前模型；并动态联动【API 文档】Tab 示例代码中 `"model"` 字段，同步当前服务的调用模型名。

**FR-3 后端推理类型统一与模型Fallback联动**（Must）：顶部概览卡展示「后端推理类型」（枚举统一为「内部推理实例」/「外部推理实例」）；【服务配置】Tab 中「模型Fallback」仅在常规路由策略或未开启流量分发时展示（是否开启 + 兜底推理实例），灰度发布策略下不展示；【全局限流】开启时展示「请求频次上限」，【请求超时时间】命名与创建页一致。

**FR-4 后端推理实例统一**（Must）：顶部概览卡展示「后端推理实例」及各实例运行状态，以绿/红圆点标识（正常=绿色 `#67C23A`、异常=红色 `#F56C6C`），与列表页和创建页对齐。

**FR-5 路由策略灰度发布（金丝雀/蓝绿）**（Must）：【服务配置】Tab 模块命名统一为【流量分发策略】，排在【缓存加速】之后，内部展示「是否开启」「策略类型」「分发方式」与「权重配置」；按权重分发与金丝雀发布展示各实例权重百分比，蓝绿发布以「当前生效 (100%)/待命 (0%)」状态徽章只读呈现，与创建/编辑页及列表页保持一致。

## 6. 详情页布局优化（概览卡 + 纯策略 Tab）

- **面包屑**：固定为「在线服务详情」（不再展示具体服务名称）。
- **顶部概览 + 基础信息卡**（常驻，切换任意 Tab 均可见）：
  1. 标题行：服务名称（加粗 18px）+ 发布状态标签（已发布绿色/未发布灰色），右侧不放操作按钮；
  2. 基础属性 3 列 key-value 网格：调用模型名、发布类型（蓝=公开发布/绿=私有发布）、后端推理类型、后端推理实例（绿/红圆点状态）、创建时间、关联模型（仅公开发布+内部推理实例展示，值为关联模型或回退到调用模型名）；服务名称已在标题行展示，网格内不重复；
  3. 操作按钮区：卡片左下角左对齐排列 `发布/停止发布`、`编辑`（跳创建页带 `&v=v2`）、`删除`、`刷新` 图标。
- **【服务配置】Tab 纯策略项**（严格对齐创建/编辑页顺序）：① 缓存加速（是否开启、缓存时间）② 流量分发策略（是否开启、策略类型、分发方式、权重配置）③ 模型Fallback（常规路由/未开启流量分发时展示，含后端推理类型与实例列表）④ 全局限流（是否开启、请求频次上限 `xxx 次/分钟`）⑤ 请求超时时间。

## 7. 数据要求（核心字段）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 服务名称 | string | 在线服务唯一名称，点击进入详情 |
| 调用模型名 | string | API 请求体 `model` 参数名（对外暴露别名） |
| 状态 | enum | 已发布 / 未发布 |
| 发布类型 | enum | 私有发布 / 公开发布 |
| 关联模型 | string? | 仅公开发布 + 内部推理实例时存在 |
| 后端推理类型 | enum | 内部推理实例 / 外部推理实例 |
| 后端推理实例 | list | 关联实例列表，含健康状态（正常/异常） |
| 路由策略 | string | 默认路由 / 按权重分发 / 金丝雀发布 / 蓝绿发布 |
| 缓存加速 | enum | 未开启 / 已开启 |
| 限流策略 | string | RPM 限流信息或 – |
| 创建时间 | datetime | 创建时间 |
