## 1. 业务背景与目标

算力加速平台「推理服务」模块下的「在线服务」页面，用于管理对外提供访问的 API 接口，配置流量分发策略、安全限流及端点状态。本页为现有产品页面的 1:1 还原，作为后续优化的基线对比版本。

目标用户：模型/推理服务的运维与管理员（如 admin 账号）。

## 2. 功能需求

**FR-1 列表展示**（Must）：以表格展示在线服务策略，列依次为：「策略名称」（可点击链接）、「模型名称」、「状态」（徽标）、「发布类型」（徽标）、「路由策略」、「缓存加速」、「后端服务类型」（展示「内部推理服务」/「外部推理服务」）、「后端服务实例」（多实例纵向列出，带健康状态圆点）、「限流策略」、「创建时间」、「操作」。

**FR-2 筛选查询**（Must）：顶部筛选卡片提供 3 个条件：「策略名称」（文本输入，占位「请输入策略名称」）、「模型名称」（下拉选择，占位「请选择模型」）、「发布类型」（下拉选择，占位「请选择发布类型」）；「查询」应用筛选，「重置」清空条件。

**FR-3 创建入口**（Must）：表格卡片左上「创建在线服务」主按钮，进入创建在线服务页面。

**FR-4 行操作**（Must）：每行操作列提供「编辑」「停止发布」/「发布」（蓝色链接）与「删除」（红色链接）。

**FR-5 分页**（Should）：底部分页栏显示总条数（「共 6 条」）、每页条数下拉（默认「10条/页」）、上一页/页码/下一页、跳转输入框（「前往」X「页」）。
