| 项 | 内容 |

| 页面 | 在线服务（`/在线服务优化/onlineservice`） |

| 更新日期 | 2026-11-05 |

## 1. 业务背景与目标

算力加速平台通过 vLLM 部署「推理实例」（负责 GPU 资源调度与进程生命周期），通过 Higress 网关将推理实例包装发布为对外暴露 API 的「在线服务」。现有版本（v1）采用 11 列宽表格展示，字段密集需横向滚动，且顶部独立筛选卡片占用较多纵向空间，同时存在「策略名称」「模型名称」「后端服务类型」「后端服务实例」等概念混用问题。v2 版本对「在线服务」列表页进行了整体重新设计：将传统宽表格重构为高信息密度的**服务卡片列表**，将多框并列筛选优化为**顶栏组合筛选器**，并统一全链路业务术语。

## 2. 功能需求

**FR-1 在线服务页面整体重新设计**（Must）：对在线服务列表页进行整体改版，涵盖视图形态重构、过滤交互优化与业务术语统一：

- **列表由表格重构为卡片列表视图**：移除 v1 需横向滚动的 11 列宽表格，改为响应式服务卡片网格（`ServiceCard`），单张卡片完整聚合单个在线服务的核心状态与运维信息：
  - **卡片头部**：展示「服务名称」（点击进入详情页）、发布状态标签（「已发布」/「未发布」）及发布范围标签（「私有发布」/「模型广场」）。
  - **调用模型名与接入地址**：展示「调用模型名」与网关「接入地址」（未发布服务显示 `–`），均提供一键复制按钮。
  - **后端推理实例与路由权重可视化**：展示后端推理类型（内部/外部推理实例）、路由策略（默认路由 / 按权重分发 / 金丝雀发布 / 蓝绿发布）、实例数量与健康状态说明 Tooltip；逐行展示各实例健康状态圆点、实例名称、模型名及流量权重进度条（蓝绿发布展示「当前生效 / 待命」状态）。
  - **高可用与安全策略标签**：集中展示「⚡ 缓存加速」、「🛡 Fallback」（仅常规路由/单实例服务展示，灰度发布策略自动隐藏）、「⏱ 限流 RPM」配置标签。
  - **底部监控指标与快捷操作**：精简展示「调用 / 失败 / Token」三项核心指标，配备灰色问号说明图标（鼠标移入浮层展示近 24 小时调用成功/失败明细及 Token 输入/输出明细，点击指标区直达详情页「用量统计」），右侧提供「编辑」「发布/停止发布」「删除」快捷操作。
- **顶部过滤条件优化（组合筛选器）**：移除 v1 独立占行、三框并列的搜索卡片，将筛选区合入列表顶栏右侧（与左侧「创建在线服务」同行）：采用前置筛选字段下拉（切换 `服务名称` / `调用模型名` / `发布类型`）+ 后置联动控件的一体化组合框（选「服务名称」为文本输入框，选「调用模型名」或「发布类型」自动切换为等宽无缝拼接的下拉选择框），支持回车/点击查询与一键重置。
- **全链路业务术语统一**：「策略名称」统一改为「服务名称」，「模型名称」统一改为「调用模型名」，「后端服务类型（内部/外部推理服务）」统一改为「后端推理类型（内部/外部推理实例）」，「后端服务实例」统一改为「后端推理实例」，与创建页、详情页完全对齐。

**FR-2 创建与行操作**（Must）：左上角「创建在线服务」跳转创建页；点击卡片标题「服务名称」跳转详情页；卡片底部操作支持「编辑」「发布」「停止发布」「删除」。

**FR-3 路由策略升级与灰度发布**（Must）：路由策略支持「按权重分发」「金丝雀发布」「蓝绿发布」三种模式。卡片视图直观展示策略类型与实例流量状态，且常规路由/单实例服务展示「Fallback」高可用标签（灰度发布服务无 Fallback）。

## 3. 数据要求

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 服务名称 | string | 在线服务唯一名称，点击进入服务详情 |
| 调用模型名 | string | API 请求体中传入的 `model` 参数名 |
| 状态 | enum | 「已发布」/「未发布」 |
| 发布类型 | enum | 「私有发布」/「公开发布」 |
| 路由策略 | string | 如「按权重分发」或「–」 |
| 缓存加速 | enum | 「未开启」/「已开启」 |
| 后端推理类型 | enum | 「内部推理实例」/「外部推理实例」 |
| 后端推理实例 | list | 关联的推理实例列表，含健康状态圆点与实例名 |
| 限流策略 | string | 限流信息或「–」 |
| 创建时间 | datetime | 创建时间 |
