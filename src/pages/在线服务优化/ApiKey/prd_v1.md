## 1. 业务背景与目标

算力加速平台通过 Higress 网关与统一认证体系为模型推理与在线服务提供鉴权访问控制。租户通过「API Key 管理」生成、查看、修改密钥，配置 Token 额度上限与 TPM 速率限流，并将密钥授权绑定至具体的「官方服务」或自建的「私有服务」，保障模型调用凭证的可控与审计。

本版本为生产环境 API Key 管理列表及 4 项核心交互弹窗（创建、编辑、服务绑定、设置限流）的 1:1 精确逆向还原。

## 2. 页面与交互需求

**FR-1 密钥列表展示**（Must）：
- **表格列定义**（共 9 列，顺序依次为：名称 → API Key → 描述 → 官方服务 → 私有服务 → 限额配置 → 白名单 → 创建时间 → 操作）：
  1. **名称**：API Key 自定义名称（如 `api-key-01`、`api-key-202507271520` 等）；
  2. **API Key**：默认掩码展示（`sk-****************************`），右侧提供快捷复制图标（蓝色 `#166EFF`，复制成功绿色反馈）与查看/隐藏眼睛图标（灰色 `#909399`，支持切换明文显示）；
  3. **描述**：API Key 的备注说明（选填，最长 200 字符）；列表单元格文字超出宽度时省略号截断（带 `title` 原生悬浮提示），空值时展示短横线「–」；
  4. **官方服务**：已绑定的平台官方预置推理服务，表头配实心圆形 `i` 图标，Hover 触发状态浮层「服务状态: 🟢 已发布 | 🔴 未发布」；支持多条目展示，带发布状态圆点（🟢 已发布 / 🔴 未发布）、服务标识及所属模型名，条目右侧配蓝色链条 Link 图标（`🔗`）；未绑定显示「–」；
  5. **私有服务**：已绑定的租户私有在线服务，表头配实心圆形 `i` 图标，Hover 触发状态浮层「服务状态: 🟢 已发布 | 🔴 未发布」；支持多条目展示，带发布状态圆点、服务名称及模型名，条目右侧配蓝色链条 Link 图标（`🔗`），可点击跳转至对应在线服务详情页；未绑定显示「–」；
  6. **限额配置**：展示当前密钥已启用的 Token 额度与 TPM 速率限流配置（如 `总Token额度：10000 Tokens`、`请求Token上限：1000 Tokens / 分钟`），未配置显示「–」；
  7. **白名单**：展示当前密钥已启用的 IP 白名单地址列表（浅蓝底 `#eef4ff`、蓝字 `#166EFF`、浅蓝边框 `#d6e4ff` 的标签样式，最多直接展示 4 条，超出显示 `+N` 汇总标签，Hover 可查看完整地址），未启用或为空时显示「–」；
  8. **创建时间**：相对时间展示（如 `5 分钟前`、`3 个月前`、`4 个月前`、`7 个月前`）；
  9. **操作**：行右侧快捷操作，采用紧凑折叠结构。直接展示常用项「编辑」「服务绑定」，右侧带「···」更多按钮，点击展开带顶部小箭头的气泡操作菜单，内含「设置限流」「设置白名单」「启用/禁用」「删除」（严格仅包含此 6 项，不多不少，hover 交互高亮，点击外部自动收起）。

**FR-2【创建 API Key】交互弹窗**（Must）：
- 点击列表左上角 `+ 新建` 唤起对话框；
- **弹窗标题**：`创建 API Key`，右侧带 `✕` 关闭按钮；
- **名称表单项**：必填项（红星 `*`），默认预填系统生成的唯一名称 `api-key-${yyyyMMddHHmm}`（共 20 位）；输入框内右浮动字符计数器 `20 / 32`（限长 32 字符）；
- **描述表单项**：选填项，占位文案 `请输入 API Key 描述（选填）`；多行文本域（textarea），内右浮动字符计数器 `0 / 200`（限长 200 字符）；
- **底部操作**：右下角提供 `取 消` 与 `确 定`（蓝色主按钮）。

**FR-3【编辑 API Key】交互弹窗**（Must）：
- 点击行操作中的 `编辑` 唤起；
- **弹窗标题**：`编辑 API Key`，右侧带 `✕` 关闭按钮；
- **名称表单项**：必填项（红星 `*`），回填当前密钥名称，输入框内右浮动字符计数器（如 `10 / 32`），支持修改；
- **描述表单项**：选填项，占位文案 `请输入 API Key 描述（选填）`；多行文本域（textarea），内右浮动字符计数器（如 `14 / 200`），回填当前密钥描述，支持修改；
- **底部操作**：右下角提供 `取 消` 与 `确 定`。

**FR-4【服务绑定】交互弹窗**（Must）：
- 点击行操作中的 `服务绑定` 唤起；
- **弹窗标题**：`服务绑定`，右侧带 `✕` 关闭按钮；
- **官方服务**：下拉选择框，默认占位文案 `请选择官方服务`，右侧带向下小箭头，展开可选择平台官方服务（如 `muxi-zgq | Qwen2-0.5B-Instruct` 等）；
- **私有服务**：下拉选择框，默认占位文案 `请选择私有服务`，右侧带向下小箭头，展开可选择租户自建在线服务（如 `deepseek-test | deepseek-v3-pro`、`gtai-72b | Qwen2.5-72B-Instruct` 等）；
- **底部操作**：右下角提供 `取 消` 与 `确 定`。

**FR-5【设置限流】交互弹窗**（Must）：
- 点击行更多操作中的 `设置限流` 唤起；
- **弹窗标题**：`设置限流`，右侧带 `✕` 关闭按钮；
- **启动Token额度**：Switch 开关；开启后展示必填项 `总Token额度 *`，输入框占位符 `0-100000000000`，后缀单位 `Tokens`；保存后联动更新列表「限额配置」列；
- **启动Token限流（TPM）**：Switch 开关；开启后展示必填项 `请求Token上限 *`，输入框占位符 `0-1000000`，后缀单位 `Tokens / 分钟`；保存后联动更新列表「限额配置」列；
- **底部操作**：右下角提供 `取 消` 与 `确 定`。

**FR-6【设置白名单】交互弹窗**（Must）：
- 点击行更多操作中的 `设置白名单` 唤起；
- **弹窗标题**：`设置白名单`，右侧带 `✕` 关闭按钮；
- **启用 IP 白名单**：Switch 开关；关闭时仅展示开关，不展示地址输入框；开启后展示「IP 地址」块状标签录入区；
- **IP 地址表单项**：支持 IPv4（如 `192.168.1.100`）、IPv6（如 `2408:400a::1`）、网段 CIDR（如 `10.0.0.0/24`、`2001:db8::/32`）；输入时支持逗号/分号/回车切分为块状标签，每个标签右侧带 `✕` 删除按钮；
- **保存逻辑**：开启并填写时，将地址块写入密钥白名单，并实时同步更新列表「白名单」列展示；关闭时清空白名单（列表显示「–」）；
- **底部操作**：右下角提供 `取 消` 与 `确 定`。

**FR-7【启用 / 禁用 API Key】交互弹窗**（Must）：
- 点击行更多操作中的 `启用` 或 `禁用` 唤起二次确认对话框；
- **弹窗标题**：`启用 API Key` 或 `禁用 API Key`，右侧带 `✕` 关闭按钮；
- **确认文案**：
  - 禁用时：`确定要禁用 API Key “{name}” 吗？禁用后通过该凭证发起的服务调用请求将被拒绝。`
  - 启用时：`确定要启用 API Key “{name}” 吗？启用后该凭证将恢复正常服务调用鉴权。`
- **保存逻辑**：点击确定后切换对应密钥状态。禁用状态下名称后展示浅灰「已禁用」标签，操作菜单动态切换为「启用」；
- **底部操作**：右下角提供 `取 消` 与 `确 定`。

**FR-8【删除确认】交互弹窗**（Must）：
- 点击行更多操作中的 `删除` 唤起二次确认对话框，防止误删密钥。

**FR-9 检索与分页**（Should）：
- 右上角支持名称搜索与一键刷新；
- 底部分页栏显示总条数、每页条数选择器、上一页/页码/下一页切换及页码跳转。
