# 模型体验 (Model Experience) 产品需求文档 (PRD)

## 1. 业务背景与目标
为开发者和业务用户提供模型推理的在线体验服务，旨在帮助用户快速了解并测试各类模型的功能与效果。用户可以直接选择名下的 API Key，关联已发布的在线模型服务，配置推理参数（提示词、Max Tokens、温度、Top-P、Frequency Penalty 等），并即时发起多轮对话或图文多模态交互体验。

## 2. 页面架构与视觉规范
- **导航与外壳**：遵循算力加速平台统一风格，左侧「模型体验」与「推理服务」同级（二级菜单），当前项高亮。
- **页面头部**：
  - 主标题：模型体验
  - 副标题：为您提供模型推理的在线体验服务，旨在帮助您快速了解并测试各类模型的功能与效果。
  - 右上角：蓝底「使用指南」按钮，点击弹出 API 快速调用指引。
- **左侧控制面板**（支持一键收起/展开）：
  - **应用类型切换**：
    - `💬 对话型应用`：纯文本大语言模型多轮对话。
    - `🖼️ 图文对话型应用`：支持图像上传与视觉多模态理解。
  - **API Key 选择**：
    - 下拉选择已创建的 API Key，列表中仅展示启用状态的 API Key，已停用项不出现。
    - 标题右侧提供 ⓘ 提示说明，悬停展示「只有启用且未开启 IP 白名单限制的 API Key 可以使用」；提示气泡挂载于页面最上层，不被面板滚动区域裁切、不被其他浮层遮挡。
    - 若选中的 Key 暂无绑定的模型服务，展示引导卡片「当前 API Key 下暂无已发布的大模型服务，请在 API Key 页面绑定已发布的大模型服务」，提供「去绑定」跳转链接。
  - **模型服务选择**：
    - 绑定有效服务的 Key 可选择对应的模型服务（如 `test-04`）。
    - 提供「重置配置」功能，一键恢复默认推理参数。
  - **系统提示词 (System Prompt)**：
    - 默认：「你是一个AI智能聊天机器人。」
  - **超参数调试滑块**：
    - **Max Tokens**：1 ~ 8196，默认 1024。
    - **温度 (Temperature)**：0.00 ~ 2.00，默认 0.70。
    - **Top-P**：0.00 ~ 1.00，默认 0.70。
    - **Frequency Penalty**：-2.00 ~ 2.00，默认 0.00。
  - **模型服务信息徽标**：
    - 模型服务：绿色徽标（如 `test-04`）。
    - 模型名称：绿色徽标（如 `qwen-2.5-7b`）。
- **右侧体验与交互区域**：
  - **无模型空状态**：
    - 标题「📖 欢迎体验大模型服务！」
    - 淡蓝条幅提示「当前 API Key 下暂无已发布的模型服务，请在 API Key 页面绑定已发布的模型服务。」
  - **对话交互态**：
    - 顶部欢迎标语与初始机器人气泡「我是模型推理体验助手，请问有什么需要我协助的？」。
    - 完整的多轮消息流、用户气泡与AI流式响应卡片。
    - 底部输入区：圆角输入框「询问任何问题」，支持回车发送，图文模式支持上传图片。
