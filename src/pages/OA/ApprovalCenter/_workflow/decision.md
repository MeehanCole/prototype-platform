## 方案 3 落地要点（A4 原型生成依据）

1. **顶部统计看板**:4 卡片(待办数 / 超时数 / 今日已处理 / 本周完成),含数字 + 趋势小图
2. **视图切换**:【看板】【列表】Segmented 切换,默认看板视图
3. **看板视图**:按审批类型(请假/报销/采购/用印)分列,卡片堆叠,展示标题+发起人+紧急标记+状态
4. **列表视图**:ElTable 风格表格(stripe + border + headerBg #fafafa),列含标题/类型/发起人/提交时间/当前节点/状态/操作
5. **Tab 分类**:待办/已办/抄送我/我发起的,Badge 显示数量
6. **详情弹窗**:ElDialog 展示申请表单 + 流转时间线 + 审批意见输入 + 操作按钮
7. **行内快捷操作**:列表操作列【同意】【驳回】(防误触二次确认)
8. **批量处理**:列表勾选 + 顶部【批量同意】
9. **筛选**:审批类型 / 状态 / 时间范围
10. **状态**:空状态、加载骨架、错误重试

## 风险与缓解

- 统计趋势图依赖后端聚合接口:原型用静态数据演示,接口未就绪时降级为纯数字
- 看板视图大数据量体验:原型限定每列展示前 N 张卡片 + "查看更多"
- 双视图维护成本:原型层面共用数据层,仅视图组件分离
