# 登录页 PRD (V2)

## 功能概述

用户通过手机号 + 验证码登录系统,提升安全性与用户体验。

## 字段定义

| 字段 | 类型 | 必填 | 校验规则 |
|---|---|---|---|
| 手机号 | string | 是 | 11 位数字,1 开头 |
| 验证码 | string | 是 | 6 位数字 |

## 交互流程

1. 用户输入手机号
2. 点击"获取验证码"按钮,按钮进入 60 秒倒计时
3. 用户输入收到的 6 位验证码
4. 点击"登录"按钮
5. 校验通过 → 跳转首页;失败 → 提示错误信息

## 异常处理

- 手机号格式错误:输入框下方红字提示
- 验证码未获取:登录按钮禁用
- 验证码错误:Toast 提示"验证码错误,请重试"
- 网络超时:Toast 提示"网络异常,请稍后重试"

## V2 改进点

- 去掉密码,降低用户记忆负担
- 验证码登录更安全
- 预留一键登录扩展接口
