# 登录页 PRD

## 功能概述

用户通过手机号 + 验证码登录系统,支持 V1(旧版)和 V2(新版)两套方案。

## V1 方案: 手机号 + 密码

### 字段

| 字段 | 类型 | 必填 | 校验规则 |
|---|---|---|---|
| 手机号 | string | 是 | 11 位数字,1 开头 |
| 密码 | string | 是 | 6-20 位,字母+数字 |

### 交互

1. 用户输入手机号和密码
2. 点击"登录"按钮
3. 校验通过后跳转首页,失败则提示错误

## V2 方案: 手机号 + 验证码

### 字段

| 字段 | 类型 | 必填 | 校验规则 |
|---|---|---|---|
| 手机号 | string | 是 | 11 位数字,1 开头 |
| 验证码 | string | 是 | 6 位数字 |

### 交互

1. 用户输入手机号
2. 点击"获取验证码"按钮,60 秒倒计时
3. 输入验证码,点击"登录"
4. 校验通过后跳转首页,失败则提示错误

### V2 相比 V1 的改进

- 去掉密码,降低用户记忆负担
- 验证码登录更安全
- 支持一键登录扩展(预留)
