# 数据看板 PRD

## 功能概述

展示 CRM 系统核心运营指标,支持按时间范围筛选。？

## 指标定义

| 指标   | 说明            | 数据来源       |
| ---- | ------------- | ---------- |
| 新增客户 | 选定周期内新增的客户数   | customer 表 |
| 成交订单 | 选定周期内已成交订单数   | order 表    |
| 营收总额 | 选定周期内成交订单金额合计 | order 表    |

## 交互流程

1. 默认展示近 7 天数据
2. 右上角下拉框切换时间范围(7 天 / 30 天)
3. 切换后三个指标卡片实时更新
4. 下方展示近期动态时间线

## 异常处理

* 数据加载中:卡片显示骨架屏

* 数据为空:卡片显示"--"

* 网络超时:Toast 提示"加载失败,请重试"
