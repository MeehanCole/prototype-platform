# 云API管理控制台 PRD

## 产品概述

云API管理统一运营平台，为云API的提供方和消费方提供完整的接口管理能力。平台分为**运营端**和**租户端**两个视角，支持接口的全生命周期管理。

## 信息架构

```
云API管理控制台
├── 顶部导航栏（TopNav）
│   ├── 云API管理 / 总览 / 平台运营
│   └── 用户菜单（账户退出）
└── 侧边导航（Sidebar）
    ├── 运营端
    │   ├── 接口管理
    │   └── 接口分类管理
    └── 租户端
        ├── 接口管理
        ├── 接口分类管理
        ├── 复杂类型参数管理
        └── 同步记录管理
```

## 功能模块

### 1. 运营端 - 接口管理（OpsInterfaces）
- 接口列表展示，支持按产品/服务、接口名称、状态、版本等多条件筛选
- 支持新增、导入、导出、发布、删除等批量操作
- 点击"编辑"跳转到接口编辑页

### 2. 运营端 - 接口分类管理（Categories）
- 接口分类的树形/列表管理
- 支持分类的增删改查

### 3. 租户端 - 接口管理（TenantInterfaces）
- 租户视角的接口列表，展示已订阅接口
- 支持全选、批量操作
- 点击"编辑"跳转到接口编辑页

### 4. 租户端 - 接口分类管理
- 复用运营端分类管理组件，数据按租户隔离

### 5. 租户端 - 复杂类型参数管理（ComplexTypes）
- 管理接口中使用的复杂类型参数（对象、数组等）
- 支持新增复杂类型（跳转到新增表单页）
- 支持编辑、删除、查看引用

### 6. 租户端 - 同步记录管理（SyncRecords）
- 记录接口/分类/配置的同步历史
- 支持按名称、类型、状态筛选
- 支持查看同步详情、重新同步、删除

### 7. 接口编辑页（EditInterface）
- 接口基本信息表单
- 入参/出参表格管理（动态增删行）
- 错误码定义
- 路由配置（调用点、后域地址、超时、鉴权等）

### 8. 新增复杂类型页（AddComplexType）
- 复杂类型定义表单
- 字段动态增删

## 核心交互流程

### 流程1：接口管理
```
接口列表 → 点击"编辑" → 接口编辑页 → 保存/发布/取消 → 返回列表
```

### 流程2：复杂类型管理
```
复杂类型列表 → 点击"新增" → 新增复杂类型表单 → 保存 → 返回列表
```

### 流程3：同步记录追踪
```
同步记录列表 → 筛选条件查询 → 查看详情 → 重新同步（失败记录）
```

## 页面流转关系

| 起点 | 操作 | 终点 |
|------|------|------|
| 运营端接口列表 | 点击"编辑" | 接口编辑页 |
| 租户端接口列表 | 点击"编辑" | 接口编辑页 |
| 复杂类型列表 | 点击"新增" | 新增复杂类型页 |
| 接口编辑页 | 点击"取消"/"保存" | 返回来源列表页 |
| 新增复杂类型页 | 点击"取消"/"保存" | 返回复杂类型列表页 |

## 异常处理

- 数据加载中：表格显示骨架屏
- 数据为空：表格显示"暂无数据"占位
- 网络超时：Toast 提示"加载失败，请重试"
- 筛选无结果：表格显示"暂无数据"
