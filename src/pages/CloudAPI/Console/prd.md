# 云API管理控制台 PRD

## Business Context
- **Target product**: 云API管理统一运营平台
- **Target tech stack**: React 18 + Vite + Tailwind CSS
- **Design system**: Ant Design 风格
- **Entry point**: CloudAPI > Console

## Feature Overview
云API管理统一运营平台，提供运营端和租户端双视角的接口全生命周期管理能力。包含接口管理、接口分类管理、复杂类型参数管理、同步记录管理等核心模块。

## Functional Requirements

### 运营端

**FR-1 接口管理（接口列表）**
- 接口列表展示：code、产品/服务、接口名称、接口中文名、接口转发类型、接口状态、版本号、是否云API、超时时间、签名鉴权等18列
- 筛选：产品/服务、接口名称、接口状态、是否云API、创建时间、更新时间
- 操作：新增、发布、删除、导入、导出
- 行操作：编辑、发布、删除
- 分页：10条/页

**FR-2 接口分类管理**
- 左侧服务树列表：支持5层级树形结构，展开/折叠、新增服务、新增子节点、删除节点
- 右侧服务信息表单：服务中文名称、服务英文名称、服务编码
- 操作：提交

**FR-3 复杂类型参数管理**
- 列表展示：类型名称、版本、产品/服务、出入参类型、类型中文描述、类型英文描述、创建时间、修改时间
- 筛选：类型名称、类型中文描述、版本、出入参类型、产品/服务
- 操作：查询、重置、新增、编辑、删除
- 分页：10条/页

### 租户端

**FR-4 接口管理**
- 与运营端接口列表共享同一组件，展示租户视角的接口数据

**FR-5 同步记录管理**
- 列表展示：code、产品/服务、接口名称、接口中文名、接口转发类型、接口状态、版本号、是否云API、目的地域、同步时间、同步结果
- 筛选：产品/服务、接口名称、版本号、同步结果、接口状态、目的地域
- 更多搜索：是否云API、同步时间范围
- 操作：查询、重置、展开/收起更多搜索
- 分页：10条/页

### 通用功能

**FR-6 新增复杂类型**
- 表单：产品/服务（必填）、类型名称（必填）、类型中文描述、类型英文描述（必填）、出入参类型（必填）
- 参数内容表格：参数名称、是否必填、类型、数组类型、是否允许NULL、中文描述、英文描述
- 操作：添加参数、保存、取消

**FR-7 编辑接口**
- 基本信息表单：产品/服务、接口名称、接口中文名、接口中文描述、接口英文描述、版本、接口转发类型、查询接口、是否云API、请求方式
- 入参表格：参数名称、是否必填、类型、数组类型、是否允许NULL、中文描述、英文描述
- 系统公共参数：placementId、appId、pke-envId
- 出参表格：同入参结构
- 错误码定义：错误码、描述，支持新增/删除
- 后端地址及限频表格：路由、后端地址、接口限频、账号限频、账号限频白名单
- 签名鉴权及其他配置：签名和鉴权、接口调用timeout值、呼入系统、负责人、变更记录
- 操作：保存、发布、取消

## Interaction Flow
1. 用户进入平台 → 默认显示同步记录管理页
2. 左侧侧边栏切换：运营端（接口管理/接口分类管理/复杂类型参数管理）、租户端（接口管理/接口分类管理/复杂类型参数管理/同步记录管理）
3. 接口列表点击「编辑」→ 跳转编辑接口页，点击「返回」回到列表
4. 复杂类型参数管理点击「新增」→ 跳转新增复杂类型页，点击「保存/取消」回到列表
5. 同步记录管理点击「更多搜索」展开额外筛选条件

## Edge Cases
- 空状态：表格无数据时显示「暂无数据」
- 删除确认：所有删除操作需二次确认弹窗
- 树节点深度限制：最多5层，超出不允许添加子节点
- 表格横向滚动：列数多的表格支持横向滚动
