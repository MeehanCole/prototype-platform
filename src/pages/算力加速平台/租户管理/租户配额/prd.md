## 1. 业务背景

租户在多个算力集群上共享资源池，但资源上限一直由运维逐集群手工配置，租户侧看不到「已用多少、上限多少、还能用多少」。项目申请资源被拒时，只能靠人工询问运维定位是哪个集群、哪类资源触顶。

租户配额页面把「租户 × 集群 × 资源类型」的用量与上限集中呈现，并提供自助调整入口，让租户管理员在不提工单的情况下评估容量与调整配额。

## 2. 功能概览

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-1 | 页面说明 | 标题「租户配额」+ 说明文字「用于管理和分配租户中所有项目的资源使用总量。」 |
| F-2 | 资源配额分组 | 「资源配额」分组标题 + 右侧刷新按钮，直接铺在白底上，不额外包大卡片 |
| F-3 | 集群配额卡片 | 每个集群一张卡片，标题为「集群：{集群名}（{集群标识}）」，右上「编辑配额」按钮 |
| F-4 | 配额表格 | 列：资源类型 / 已使用 / 配额 / 余量（四列居中）；行：CPU 限制、CPU 请求、内存限制、内存请求；行间虚线分隔 |
| F-5 | 不限制形态 | 配额为「不限制」时，已使用显示 `-`，配额与余量均显示「不限制」 |
| F-6 | 编辑配额 | 弹窗按行填写配额数值或勾选「不限制」，保存后本页数值即时更新 |
| F-7 | 刷新 | 点击刷新按钮重新拉取用量，上次更新时间记录在按钮悬浮提示中 |

## 4. 功能需求详单

### FR-1 集群配额卡片

- **优先级**：P0
- **描述**：按集群逐张渲染卡片，卡片之间上下间距 16px，整体置于「资源配额」白底描边容器内。
- **卡片头**：左侧标题 `集群：{集群名}（{集群标识}）`，集群名加粗黑色（15px），括号内标识为灰色常规字重；右侧主色实心按钮「编辑配额」，含铅笔图标。

### FR-2 配额表格

| 列 | 内容 | 说明 |
| --- | --- | --- |
| 资源类型 | CPU 限制 / CPU 请求 / 内存限制 / 内存请求 | 居中；「限制」行带资源图标（CPU 灰底芯片、内存绿底内存条），「请求」行图标位留空对齐 |
| 已使用 | 数值 + 单位 | CPU 单位「核」，内存单位「GiB」；使用率 ≥80% 时数值后追加红色百分比标签 |
| 配额 | 数值 + 单位 或「不限制」 | 来自租户配额配置 |
| 余量 | 配额 − 已使用 | 配额为「不限制」时余量同样显示「不限制」 |

### FR-3 编辑配额弹窗

弹窗复用通用件 `src/lib/quota-dialog`（与「编辑项目配额」同一套），按设计稿还原：

- **触发**：点击卡片右上「编辑配额」。
- **头部**：标题「编辑租户（{租户名}）配额」+ 两行上下文 `当前租户：{租户名}`、`当前集群：{集群名}（{集群标识}）` + 灰色提示「注：设置（租户、项目）配额后，请同时设置默认容器配额，防止容器组无法启动。」，右上 X。
- **设置配额**：两列两行 —— CPU 预留（核）/ 内存预留（GiB）一行，CPU 限制（核）/ 内存限制（GiB）一行；空值以占位「不预留」「不限制」表示，输入只接受数字，单位固定显示在输入框右内侧。
- **高级设置**：标题右侧折叠箭头（默认展开，收起后子项一并隐藏）。子项自上而下：
  1. **数据存储**：标签右侧内联问号图标，鼠标移入才浮出说明「数据存储配额主要用于存放数据集、模型文件等；留空或填 0 代表不开启数据存储空间。」；输入框占位「请输入存储空间容量」，单位 GB；输入框沿用「设置配额」两列栅格，与上方 CPU / 内存输入框左边缘对齐且等宽；右侧并列「当前系统存储容量：1000 GB ｜ 当前剩余可分配配额：200 GB」，与输入行同一行展示。不再展示蓝色超分提示块与 CircleAlert 图标。
  2. **GPU 配额**：标题下方左对齐蓝色圆形「+」，新增一组「型号 + 数量（卡）」，可删除。
- **无应用资源**：租户维度不展示「应用资源」表格，也不展示「项目可用配额」汇总条。
- **底部**：「取消」（描边）/「确定」（主色实心）；GPU 行未填型号或数量时在底部提示错误。
- **保存**：CPU / 内存 四项回写卡片表格（预留 → 「请求」行，限制 → 「限制」行），关闭弹窗，余量随即刷新（原型不落库）。

### FR-4 刷新

- 点击「资源配额」右侧刷新按钮，模拟重新拉取用量，上次更新时间以悬浮提示（`刷新（上次更新：…）`）呈现，页面不额外占用一行文案。

## 5. 业务规则与校验

| # | 场景 | 规则 | 提示 |
| --- | --- | --- | --- |
| 1 | 配额为不限制 | 已使用显示 `-`，配额/余量显示「不限制」 | — |
| 2 | 输入非数字 | 过滤掉非数字字符 | — |
| 3 | 未填数值 | 阻断保存 | 「请填写「{资源名}」的配额数值」 |
| 4 | 配额小于已使用 | 阻断保存 | 「「{资源名}」配额不能小于已使用量 {已使用}」 |
| 5 | 使用率 ≥80% | 已使用数值后展示红色百分比标签 | — |

## 6. 边界与暂不包含

- 页面不包含配额变更历史、审批流与告警订阅，后续迭代补充。
- 集群列表、资源类型、单位均由后端返回，原型内为 Mock；新增资源类型（如 GPU / 存储）时表格行自动扩展。
- 「总览 / 项目管理 / 授权集群 / 租户成员 / 租户角色」菜单项仅占位，未实现页面。

## 7. 验收标准

1. 进入页面可见设计稿的「租户管理」左侧菜单，「租户配额」为选中态（蓝底白字）。
2. 主内容区标题、说明、`资源配额` 分组与刷新按钮位置与设计稿一致。
3. 至少两张集群卡片，表格 4 行 4 列，第二张卡片全部为「不限制」形态。
4. 点击「编辑配额」可打开弹窗，取消/关闭/保存均正常，保存后卡片数值更新。
5. 1440×900 下无横向滚动条、无文字重叠。
