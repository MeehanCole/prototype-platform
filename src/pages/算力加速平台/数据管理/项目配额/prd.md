## 1. 业务背景

项目是租户内资源使用的实际承载方。项目负责人需要确认当前项目在各资源维度上「有没有上限、还剩多少」，才能判断新服务能否上线、是否需要向租户管理员申请提额。

项目概览原本只展示基础信息，「配额」作为独立 Tab 承载资源上限与用量的只读视图，避免租户配额与项目配额混淆。

## 4. 功能需求详单

### FR-1 项目基本信息

- **优先级**：P0
- **描述**：单张描边卡片，内部为 4 列栅格，共 7 个字段，每个字段「上行值 + 下行灰色标签 + 左侧图标」。
- **字段**：名称 / 租户 / 创建者 / 创建时间 / 项目成员 / 服务账户 / 描述。
- **管理按钮**：卡片右上，主色实心「管理」，点击展开气泡菜单，菜单项包含编辑项目信息 / 编辑项目配额 / 编辑容器配额 / 删除。

### FR-2 Tab 栏

- 浅灰底条内排列 4 个 Tab，选中项为主色实心底 + 白字。
- 非「配额」Tab 统一展示「暂无数据」占位区，避免空白页。

### FR-3 容器配额

| 行 | 资源类型 | 列 2 | 列 3 |
| --- | --- | --- | --- |
| 1 | CPU | CPU 请求 | CPU 限制 |
| 2 | 内存 | 内存请求 | 内存限制 |

- 每行一张长条卡片，左侧「图标 + CPU/内存」并标注「资源类型」，右侧两列展示请求/限制值。

### FR-4 项目配额

- 9 行：CPU 限制 / CPU 请求 / 内存限制 / 内存请求 / 容器组 / 服务 / 有状态副本集 / 守护进程集 / 数据存储。
- 新增「数据存储」行，展示项目可使用的存储配额与余量，单位 GB。
- 计算类资源（CPU、内存）在无用量数据时已使用显示 `-`；对象类资源（容器组、服务、有状态副本集、守护进程集）展示整数用量；数据存储无用量数据时已使用显示 `-`，单位 GB。
- 数据存储与其他项目配额行同步：编辑项目配额弹窗中的「数据存储」保存后回写此行配额与余量；留空表示不限制。
- 配额与余量为「不限制」时直接展示文案，不显示数字。

### FR-5 管理下拉

- **触发**：点击基本信息卡右上「管理」。
- **形态**：贴靠按钮右下方 4px 的气泡菜单，宽 152px，带向上小三角、浅灰描边与柔和阴影，圆角 4px。
- **菜单项**：编辑项目信息 / 编辑项目配额 / 编辑容器配额 / 分割线 / 删除（删除与其它项同为深色，仅一次确认）。
- **关闭**：点击菜单外任意位置自动关闭；再次点「管理」也可收起。

### FR-6 编辑项目配额 / 编辑容器配额

弹窗复用通用件 `src/lib/quota-dialog`，与「编辑租户配额」同一套结构，按设计稿还原：

- **头部**：标题「编辑项目配额」/「编辑容器配额」+ 上下文行 `当前项目：{项目名}` + 灰色提示「注：设置（租户、项目）配额后，请同时设置默认容器配额，防止容器组无法启动。」，右上 X。
- **项目可用配额**（仅编辑项目配额时显示）：浅蓝底（`#c7deef`）汇总条，左「资源预留：CPU …，内存 …」右「资源限制：CPU …，内存 …」，随输入实时联动。
- **设置配额**：两列两行字段 —— CPU 预留（核）/ CPU 限制（核）/ 内存预留（GiB）/ 内存限制（GiB）；空值以占位「不预留」「不限制」表示，输入只接受数字，单位固定显示在输入框右内侧。
- **高级设置**：标题右侧折叠箭头（默认展开，收起后其下三个子项一并隐藏）。子项自上而下：
  1. **数据存储**：新增数据存储配额配置能力，用于限制项目存放数据集、模型文件等数据的容量；标签右侧内联问号图标，鼠标移入浮出说明「数据存储配额主要用于存放数据集、模型文件等；留空或填 0 代表不开启数据存储空间。」；输入框占位「请输入存储空间容量」，单位 GB；输入框沿用「设置配额」两列栅格，与上方 CPU / 内存输入框左边缘对齐且等宽；右侧并列展示容量提示「当前系统存储容量：1000 GB ｜ 当前剩余可分配配额：200 GB」，与输入行同排展示。留空表示不限制。
  2. **GPU 配额**：标题下方左对齐蓝色圆形「+」，新增一组「型号 + 数量（卡）」，可删除。
  3. **应用资源**：标题下方左对齐蓝色圆形「+」；两列表格「资源 / 配额」，按设计稿只列一行「容器组」。该区块仅弹窗内演示，确定后不回写页面表格。
- **差异**：编辑容器配额时只保留「设置配额」与「高级设置」，字段名改用「请求」（CPU 请求 / 内存请求，空值占位「不限制」），不展示项目可用配额、数据存储、GPU 配额与应用资源。
- **底部**：「取消」（描边）/「确定」（主色实心，宽 64px 起）。
- **保存**：CPU / 内存四项与「数据存储」回写卡片，「余量」按「配额 − 已使用」重算；应用资源（容器组数量）不参与回写；提示「项目配额已保存」/「容器配额已保存」。

### FR-7 编辑项目信息

- 项目名称、所属租户只读（名称后提示「名称创建后不可修改」）。
- 项目成员为数字输入；描述为 3 行文本框。
- 保存后基本信息卡「项目成员」「描述」更新，提示「项目信息已更新」。

### FR-8 删除项目

- 二次确认弹窗：红色感叹号 + `确认删除项目 {项目名} 吗？` + 说明「删除后项目下的工作负载与配额配置将一并释放，且无法恢复。」+ 「取消 / 确认删除（红）」。
- 确认后主内容替换为「项目已删除」空态（图标 + 标题 + 说明 + 「撤销删除」）。
- 「撤销删除」恢复删除前的项目信息与配额，提示「已恢复项目」。

## 5. 业务规则与校验

| # | 场景 | 规则 | 提示 |
| --- | --- | --- | --- |
| 1 | 配额未设置 | 配额与余量均显示「不限制」 | — |
| 2 | 用量未知 | 已使用显示 `-` | — |
| 3 | 文案超长 | 值单行省略，悬浮显示全文 | — |
| 4 | 配额输入非数字 | 过滤非数字字符 | — |
| 5 | 配额为空 | 阻断保存 | 「请填写「{资源名}」的配额数值」 |
| 6 | 配额小于已使用 | 阻断保存 | 「「{资源名}」配额不能小于已使用量 {已使用}」 |
| 7 | 删除项目 | 必须二次确认，确认后进入空态并支持撤销 | — |

## 6. 边界与暂不包含

- 配额编辑仅在页面内生效（Mock），刷新后回到初始值；租户级调整在「租户管理 → 租户配额」。
- 「资源状态 / 用量统计 / 元数据」Tab 仅占位。
- 左侧为算力加速平台数据管理外壳菜单，当前页「项目配额」高亮；其它菜单仅占位。

## 7. 验收标准

1. 左侧为算力加速平台数据管理外壳菜单，「项目配额」为当前高亮项，样式与平台外壳一致（浅蓝底 + 主题蓝字）。
2. 主内容区依次为标题「项目概览」、说明文字、项目基本信息卡（含「管理」按钮）、Tab 栏。
3. 「配额」Tab 下依次展示「容器配额」2 行与「项目配额」8 行，行卡片为独立描边卡片、列名内嵌为灰色小字。
4. 点击「管理」弹出 4 项气泡菜单；编辑项目配额、编辑容器配额、编辑项目信息三个弹窗均可打开、校验、保存并即时反映到卡片。
5. 删除项目二次确认后进入空态，「撤销删除」可恢复。
6. 1440×900 下无横向滚动条、无文字重叠。
