| 项目 | 内容 |

## 业务背景

性能评估用于对在线推理服务做文本性能压测。用户在性能评估列表页点击创建后，进入本表单页一次性完成评估任务定义：选择被评估的推理服务、确定数据集来源与规模、选择并发压测策略与参数、按需开启高级能力（预热、前缀缓存、SLA 判定）。

本页面为原型演示页，仅还原信息结构与交互形态，数据为前端 Mock，不做真实调度与压测。

## 页面结构

1. 全局外壳：顶部导航 + 左侧导航（算力评测 → 性能评估 高亮）
2. 顶部返回栏：返回箭头 + 竖线 + 页面标题
3. 基本信息
4. 评估对象
5. 评估配置
6. 高级配置
7. 底部操作区：取消 / 创建

## 功能说明

### 返回栏

- 点击左侧返回箭头回到性能评估列表页，不保留已填内容。
- 区块标题左侧为 3px 蓝色竖条，标题为 15px 粗体。

### 基本信息

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 评估类型 | 单选 | 是 | 当前仅支持文本生成，默认选中，不可取消 |
| 名称 | 单行输入 | 是 | 最多 50 字，实时显示计数 |
| 描述 | 多行文本 | 否 | 最多 200 字，实时显示计数 |

### 评估对象

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 对象类型 | 单选 | 是 | 当前仅支持推理服务，默认选中 |
| 选择服务 | 下拉 | 是 | 默认未选，占位文案为请选择推理服务 |

选择服务下拉面板：

- 与输入框等宽，带阴影、圆角与顶部小三角，点击外部区域关闭。
- 面板顶部为三段筛选：全部 / 内部推理服务 / 外部推理服务，选中项蓝底白字。
- 下方按来源分组展示，分组标题为浅灰小字：内部推理服务含 test-nvshare；外部推理服务含 阿里不完整路径、外部服务、demo-18080、demo-18082、阿里百炼服务。
- 选项为单行文本，点击即选中并回填到输入框，已选项文字为蓝色。

### 评估配置

#### 数据集来源

- 单选两项：内部合成数据（默认选中）、平台数据集。
- 选中「内部合成数据」时展示合成数据参数容器，容器顶部为灰色提示条，提示算法将根据以下参数随机生成请求内容，并已填入最佳实践默认值。
- 选中「平台数据集」时隐藏合成数据参数容器，改为展示数据集选择器与版本选择器。

合成数据参数（3 列网格）：

| 参数 | 必填 | 默认值 | 单位 |
| --- | --- | --- | --- |
| 平均输入长度 | 是 | 1024 | tokens |
| 平均输出长度 | 是 | 256 | tokens |
| 数据集条数 | 是 | 1000 | 条 |
| 输入长度标准差 | 否 | 0 | 无 |
| 输出长度标准差 | 否 | 0 | 无 |

##### 平台数据集

**名称检索**

- 数据集选择器与「选择服务」同构：560px 高 34px 按钮，右侧下拉箭头，点击展开浮层，点击外部区域关闭。
- 平台数据集不做分类，浮层内不设标签页筛选，改为顶部一个搜索框，按名称模糊检索（大小写不敏感的子串匹配）。
- 列表项为单行：数据集名称 + 标签 chips（来自数据集管理里配置的标签，浅蓝底蓝字，全量展示）；不展示版本数、最新版本等附加信息；选中项名称高亮为品牌蓝。
- 按钮内只回填数据集名称，不展示标签；名称过长时悬停显示完整名称。
- 数据来源为数据集管理列表（读取同一份本地存储，包含新建的数据集）。
- 搜索无结果时展示「未找到匹配的数据集」。

**版本选择**

- 选中后按钮内只回填数据集名称，不再展示标签与详情卡；按钮右侧出现版本下拉（188px），默认选中最新版本。

**清空选项**

- 搜索框有内容时右侧出现 ✕，点击清空关键字并恢复完整列表。
- 已选数据集后，选择框内名称右侧出现 ✕，点击清空已选数据集与版本、收起浮层（不触发下拉展开），创建按钮随之置灰。

**说明**

- 选择器下方常驻一行说明：输入名称即可模糊检索平台数据集，并可跳转数据集管理新增或维护；不提及数据集状态。

#### 评估模式

- 单选两项：固定场景模式（默认选中）、高级探索模式。

#### 参数配置

上方为三张策略选项卡，等宽排列，单选：

1. 固定并发场景（默认选中，标题居中）：在固定并发请求数下评测服务的响应延迟、吞吐和稳定性。
2. 固定 QPS 场景（标题居中）：按指定请求速率持续发起请求，评测服务在目标流量下的表现。
3. 固定 QPS + 最大并发上限场景（标题居中）：按指定请求速率发起请求，并限制同时在途请求数。

选中态为浅蓝底 + 蓝色描边；切换选项卡只改变选中样式，不改动下方参数表中的已填数值。

下方为参数表，三列：参数 / 数值 / 描述。

| 参数 | 必填 | 默认值 | 描述 |
| --- | --- | --- | --- |
| 并发请求数 | 是 | 10 | 个，正整数，范围：1~512，同时保持的在途请求数量。数值越大，对服务的并发压力越高。 |
| 首 Token 并发上限 | 否 | 空 | 个，正整数，范围：1~512，同时等待首 Token 的请求上限，用于限制 prompt 处理阶段的并发压力。必须小于等于并发请求数。 |
| 并发爬坡时间 | 否 | 空 | 秒，正整数，范围：1~600，在指定时间内从低并发逐步提升到目标并发，避免一开始就达到目标并发。 |
| 评测结束方式 | 是 | 按请求总数 | 选择评测结束条件：按请求总数结束，或按评测时长结束。 |
| 请求总数 | 是 | 100 | 个，正整数，范围：1~100000，本次评测最多发起的请求数量。 |

### 高级配置

标题右侧有灰色辅助说明：默认关闭，仅供高阶性能调优使用。下方为 4 张卡片（宽度 760px，与参数配置区左对齐），每张含开关 + 标题 + 说明，默认全部关闭：

| 配置项 | 说明 |
| --- | --- |
| 可靠性配置 | 多轮重复采样与自适应防抖，消除系统偶发误差，确保压测数据具备高置信度统计学参考价值 |
| 冷启动预热配置 | 正式计分前发送请求，激发 GPU 显存池，防止冷启动干扰指标结果 |
| 前缀缓存配置 | 模拟所有请求共享一段极长的系统提示词，专门评估 KV Cache 命中率 |
| SLA 判定配置 | 统计同时满足延迟阈值的请求，任何一项超阈值的请求不计入 SLA 达标吞吐率 |

### 底部操作区

- 取消：返回性能评估列表页，不保存。
- 创建：名称与服务均已填写、且数据集来源为「平台数据集」时已选数据集与版本，才可用；提交后返回列表页（原型不落库）。

## 交互与校验

1. 必填项：评估类型、名称、选择服务、数据集来源、评估模式、并发请求数、评测结束方式、请求总数。
2. 创建按钮在名称为空、未选择服务、或数据集来源为「平台数据集」但未选数据集/版本时置灰不可点。
3. 名称与描述输入超长时截断，不做报错提示。
4. 所有输入控件聚焦时描边变蓝，与平台表单风格一致。

## 非功能要求

- 纯前端实现，无接口调用，刷新后状态重置。
- 布局使用 Tailwind 原子类，不写内联样式。
- 表单列宽 560px；参数配置区与高级配置卡片区宽 760px，两者左对齐，窄屏下横向滚动，不做响应式重排。
