## 1. 业务背景

「数据管理」下的数据集读写全部依赖租户/项目级的数据存储空间——底层为 RustFS 等 S3 兼容对象存储桶，平台侧需先完成空间开通（建桶、分配租户前缀、下发访问凭证）才能登记与上传数据集。

未开通时，如果仍按常规进入「数据集管理」，用户会看到一张空表与可点击的「创建数据集」按钮，容易误判为数据丢失或功能故障，并在提交后才失败。因此需要把「未开通」作为一种独立、可评审的页面状态呈现：进入即说明原因，并阻断所有写入入口。

## 2. 功能概览

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-1 | 阻断提示 | 进入页面即弹出「未检测到数据集空间」，说明当前租户/项目尚未创建数据存储空间并提示联系管理员；弹窗底部提供「返回」主按钮（另有右上角 X） |
| F-2 | 空列表 | 未开通时不存在任何数据集，表格仅展示空态文案「当前租户/项目未开通数据存储空间，请联系管理员」，分页控件隐藏 |
| F-3 | 写入入口置灰 | 「创建数据集 / 新增版本 / 上传文件」统一置灰不可点击，并带悬浮说明；不反复弹窗、不进入原流程 |

## 3. 功能需求详单

### FR-1 阻断提示弹窗

- **优先级**：P0
- **描述**：页面加载完成即弹出提示弹窗，居中显示。
- **视觉**：宽 420px 白底弹窗；顶部居中「数据库 + 存储块」双色插画（蓝色数据库柱体 + 金色存储块）；标题「未检测到数据集空间」（16px 加粗）；说明文案两行（13px，灰色 #86909c）；右上角关闭按钮；无底部操作按钮。
- **文案**：系统检测到当前租户/项目尚未在平台中创建数据存储空间，您<br/>无法直接读取或上传数据集。请联系管理员
- **业务规则**：文案固定断句，不随容器宽度重排，避免出现单字成行。

### FR-2 空列表

- **优先级**：P1
- **描述**：关掉提示后，页面回到列表，表格内不展示任何数据集，仅保留表头与空态文案。
- **业务规则**：
  1. 未开通存储空间意味着没有任何可落地的数据，页面不得读取或展示历史数据集。
  2. 空态文案：「当前租户/项目未开通数据存储空间，请联系管理员」。
  3. 分页控件在无数据时隐藏，避免出现「1 / 1」的无意义页码。
  4. 未开通状态下不写回本地存储，避免空数组覆盖既有数据集。

### FR-3 写入入口置灰

- **优先级**：P0
- **描述**：三个写入入口在未开通状态下置灰不可点击，作为「已不可用」的静态事实，而非点击后才报错。
- **业务规则**：
  1. 列表页「创建数据集」→ 置灰（浅蓝底），悬浮提示「未开通数据存储空间，暂不可创建数据集」。
  2. 列表页「新增版本」「上传文件」→ 文字链接置灰（`#c9cdd4`），不可点击。
  3. 详情页「新建版本」「上传文件」→ 置灰，悬浮说明同义。
  4. 创建数据集页「创建」→ 置灰不可提交。
  5. 只读操作不置灰：搜索、分页、详情、编辑名称、编辑描述、删除均保持可用。

## 4. 数据要求

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| configured | boolean | 当前租户/项目是否已创建数据存储空间 |
| provider | string | 存储引擎，默认 `RustFS` |
| bucket | string | 数据桶，默认 `datasets-pool` |
| updatedAt | string | 配置更新时间 |

本地持久化键：`calspeed.storage.space.v1`。

## 5. 交互流程

1. 进入「未开通数据空间」→ 渲染空列表（仅表头）→ 自动弹出阻断提示（含「返回」按钮与 X）。
2. 点「返回」或 X → 收起提示，停留在本页查看空列表（本页为评审用异常态页，不跳转）。
3. 关闭提示后写入入口均保持置灰，无法发起创建/上传。
4. 真实环境（非评审页）关闭提示则视为离开该模块，退回上一页（无历史则回平台首页总览）。
3. 点「创建数据集」→ 再次弹出提示 → 关闭后仍停留在列表。
4. 管理员完成空间开通（`configured: true`）后，本状态不再出现，恢复「数据集管理」正常流程。

## 7. 边界情况

| 场景 | 处理 |
| --- | --- |
| 关闭提示后刷新 | 重新弹出提示（未开通为页面固有状态） |
| 本地存有历史数据集 | 未开通时不读取、不展示，避免误导为「数据丢失」 |
| 未开通时离开页面 | 不写回本地存储，既有数据集保持不变 |
| 直接访问详情页 | 详情页同样接受 `?noSpace=1` 注入，写入入口被拦截 |
| 已开通环境误入本页 | 本页强制呈现未开通态，仅用于评审；真实环境由 `configured` 决定 |
| 提示被关闭后无任何入口再打开 | 刷新页面即可复现；写入入口点击同样复现 |
