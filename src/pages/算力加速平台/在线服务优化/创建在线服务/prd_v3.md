## 1. 页面定位

「在线服务」列表页点击「创建在线服务」或行内「编辑」后的创建/编辑表单页。v3 在 v2 术语统一与面板化改造的基础上，只重做「流量分发策略」面板内部的编辑控件与比例表达，**权重计算、互补逻辑、蓝绿二选一语义均未改变**。

## 2. 功能需求

**FR-1 服务名称统一**（Must）：表单第 1 项由「策略名称」改为「服务名称」，占位文案改为「请输入服务名称」。

**FR-2 后端推理类型与选项优化**（Must）：表单项「后端服务类型」改为「后端推理类型」，单选选项由「内部推理服务 / 外部推理服务」改为「内部推理实例 / 外部推理实例」。

**FR-3 公开发布与关联模型**（Must）：仅当「发布类型」选择「公开发布」且「后端推理类型」为「内部推理实例」时展示「关联模型」下拉（初次切换默认未选中，占位「请选择关联模型」）；切换为「外部推理实例」时不展示「关联模型」。

- 选择关联模型后，「调用模型名」自动填充该关联模型名（无需再依据首个推理实例），用户仍可手动修改作为对外暴露的请求参数别名。
- 「后端推理实例」下拉按关联模型过滤：仅展示与关联模型相同模型名称的推理实例；已选中的不匹配实例自动清除；若当前关联模型无任何匹配实例，展示空态提示引导先部署相同模型的实例。

**FR-4 后端推理实例统一**（Must）：必填多选下拉标签统一为「后端推理实例」，未选占位文案改为「请选择后端推理实例」，下拉项同时展示实例名称、所属模型与运行状态（「运行中」/「已关机」）；在关联模型过滤场景下仅展示匹配实例，并提供无匹配空态提示。

**FR-5 调用模型名统一，改为纯手动填写**（Must）：表单项由「模型名称」改为「调用模型名」，占位文案「请输入调用模型名」。**取消与「后端推理实例」的联动**：选中/清空后端推理实例均不再自动回填或清空该字段，也不再取首个实例的模型名称。例外：公开发布且已关联模型时，仍自动填入该关联模型名（用户可改为别名）。该字段作为对外暴露的请求参数别名，对应在线服务详情【API 文档】示例代码中 `"model"` 字段。

**FR-6 流量分发策略面板与三策略分化编辑**（Must）：表单项由「路由策略」升级为「流量分发策略」，采用与「缓存加速 / 全局限流」一致的开关控件开启。

- **与实例数量的联动（必选规则）**：选 0 或 1 个后端推理实例时，「流量分发策略」为非必选（无红色 *），开关可自由开启/关闭（默认关闭）；选 **≥ 2 个**后端推理实例时，「流量分发策略」升级为**必选项**（标签显示红色 *），开关自动开启并**置灰锁定不可关闭**，右侧提示「选择多个后端推理实例时，必须配置流量分发策略」。
- **面板结构**：策略切换与权重配置合并在**同一个面板**内（参考 Google Cloud Run「修订版本流量」、K8s / Argo Rollouts `setWeight`），自上而下为：① 顶栏（策略分段控件 + 策略说明「?」气泡 + 右侧策略关键数值）；② **堆叠占比条**（6px，按各实例占比切分色段，段间 2px 白色间隙）；③ 实例行列表（行间仅 1px 水平分隔线，不使用灰底表头与列间竖线）；④ 可选底部校验条。策略说明默认收起，移入 / 聚焦 / 点击「?」才展开。
- **比例可视化集中化**：**不在每行末尾放进度条**（行内图形噪音，且与数值重复），改为面板顶部一条堆叠色带统一表达全部实例的占比；行首 8px 色点与色带段落颜色一一对应，形成图例关系。色带随权重实时变化（`flex-grow` 过渡）。
- **常规路由（按权重分发）**：策略分段控件为单项只读态（`tabIndex=-1`），外观与灰度选中项一致。每行 = 色点 + 实例名称（自适应省略）+ **权重输入框**（`96×32`，单位 `%` 内嵌于框内右端，不再外挂灰色 `%` 字符）。**取消上下步进按钮**（从 50 调到 70 需点 20 次的交互不成立），改为输入框聚焦时 `↑ / ↓` 键步进 ±5。输入值 clamp 到 0~100，禁止 `9999%` 这类无意义输入。支持任意数量（含 1）实例；**手动增删实例时自动按最新数量均分 100%**（编辑态首次进入保留已保存权重，仅在用户手动增删实例后重新均分）。实例数 > 1 时顶栏提供「均分」文字按钮，一键按 `⌊100/n⌋` 重排、余数给第一个实例。顶栏右侧「已分配」实时联动：等于 100% 时**只显示一个绿色数值**，不等于 100% 时才展开为「90% / 100%」红色对照，并在面板底部出现校验条「还差 N% / 已超出 N%，各实例权重之和必须等于 100%」；合计 100% 时无任何常驻说明。未选实例时列表区展示空态「请先在上方选择后端推理实例」。
- **金丝雀发布（单一自由度）**：金丝雀的本质只有一个自由度（新版本拿多少流量），因此**只提供一个滑杆 + 一个数值输入**控制「金丝雀流量」，滑杆 0~100、`step=1`，下方提供 `1% / 5% / 10% / 25% / 50%` 快捷刻度（对齐 Flagger / Argo Rollouts 的常用灰度比例）。**基线百分比不再可编辑**，而是作为结果只读展示（`100% - 金丝雀流量`），避免用户自行推导互补约束。滑杆下方两行结果展示：色点 + 实例名 + 「基线」/「金丝雀」角色标签 + 只读百分比，颜色与顶部堆叠条一致（基线浅蓝 `#9DBDF7`、金丝雀主色 `#166EFF`）。
- **蓝绿发布（零自由度）**：不展示权重输入。两行展示：行首单选圆点 + 实例名 + 状态徽章（「主用」绿色 / 「备用」灰色）+ 行尾 `100%` / `0%`。**切换不再由「点击整行」触发**（生产控制台里误点一行等于切走全量流量），改为备用行右侧显式的「切换到此实例」按钮：首次点击进入行内二次确认（「确认 / 取消」，蓝色主按钮 + 描边次按钮），确认后才写入选中态；主用行右侧以 `—` 占位，保持两行右侧宽度一致、切换后不跳动。
- **灰度可用性约束**：**仅当选中恰好 2 个后端推理实例时「灰度发布策略」单选可用**；实例数为 0、1 或 ≥3 时该单选置灰禁用并提示「（灰度发布需选择 2 个后端推理实例）」；若已选灰度后实例数变为非 2，自动回退为「常规路由策略」。灰度两种策略在面板顶栏用**双项分段控件**互斥切换（`role="tablist"` / `role="tab"` / `aria-selected`），不使用下拉框。
- **后端推理实例可用性约束**：下拉列表中「已关机」实例整行置灰禁用（`cursor-not-allowed`），状态显示「已关机（不可选）」，不可勾选参与路由；仅「运行中」实例可被选入流量分发策略。
- **高可用与安全 · 模型Fallback联动**：常规路由策略（或单实例未开启流量分发策略）下保留「模型Fallback」兜底配置（支持选择内部/外部推理实例及运行中的兜底推理实例）；灰度发布策略下同样保留「模型Fallback」兜底配置（不再隐藏/自动关闭）。保留全局限流（RPM）及请求超时时间配置。
