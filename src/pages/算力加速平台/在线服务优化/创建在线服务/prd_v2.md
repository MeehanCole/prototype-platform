## 1. 页面定位

「在线服务」列表页点击「创建在线服务」或行内「编辑」后的创建/编辑表单页。v2 版本统一了「服务名称」「调用模型名」「后端推理类型」「后端推理实例」命名，并新增关联后端推理实例后自动填充首个实例模型名称到「调用模型名」的联动体验。

## 2. 功能需求

**FR-1 服务名称统一**（Must）：表单第 1 项由「策略名称」改为「服务名称」，占位文案改为「请输入服务名称」。

**FR-2 后端推理类型与选项优化**（Must）：表单项「后端服务类型」改为「后端推理类型」，单选选项由「内部推理服务 / 外部推理服务」改为「内部推理实例 / 外部推理实例」。

**FR-3 公开发布与关联模型**（Must）：仅当「发布类型」选择「公开发布」且「后端推理类型」为「内部推理实例」时展示「关联模型」下拉（初次切换默认未选中，占位「请选择关联模型」）；切换为「外部推理实例」时不展示「关联模型」。

- 选择关联模型后，「调用模型名」自动填充该关联模型名（无需再依据首个推理实例），用户仍可手动修改作为对外暴露的请求参数别名。
- 「后端推理实例」下拉按关联模型过滤：仅展示与关联模型相同模型名称的推理实例；已选中的不匹配实例自动清除；若当前关联模型无任何匹配实例，展示空态提示引导先部署相同模型的实例。

**FR-4 后端推理实例统一**（Must）：必填多选下拉标签统一为「后端推理实例」，未选占位文案改为「请选择后端推理实例」，下拉项同时展示实例名称、所属模型与运行状态（「运行中」/「已关机」）；在关联模型过滤场景下仅展示匹配实例，并提供无匹配空态提示。

**FR-5 调用模型名统一与自动填充**（Must）：表单项由「模型名称」改为「调用模型名」。填充规则分级：① 公开发布且已关联模型时，自动填充该关联模型名；② 私有发布或未关联模型时，按所选第一个后端推理实例的模型名称自动填充（清空全部实例时自动清空）；③ 以上两种自动填充均可在用户未手动修改前动态同步，用户随时可手动修改「调用模型名」作为对外暴露的请求参数别名。对应在线服务详情【API 文档】示例代码中 "model" 字段。

**FR-6 路由策略升级支持灰度发布与模型Fallback联动**（Must）：表单项由「路由策略」升级为「流量分发策略」，采用与「缓存加速 / 全局限流」一致的开关控件开启。

- **与实例数量的联动（必选规则）**：选 0 或 1 个后端推理实例时，「流量分发策略」为非必选（无红色 *），开关可自由开启/关闭（默认关闭）；选 **≥ 2 个**后端推理实例时，「流量分发策略」升级为**必选项**（标签显示红色 *），开关自动开启并**置灰锁定不可关闭**，右侧提示「选择多个后端推理实例时，必须配置流量分发策略」。
- **策略配置面板（统一容器形态）**：策略切换与权重配置合并为**同一个面板**，不再是「策略选择框 + 权重表格」两块独立组件拼接（参考 Google Cloud Run「修订版本流量」、K8s / Argo Rollouts `setWeight` 的列表形态）。面板结构为：顶栏（左：策略分段控件）→ 1px 分隔线 → 轻量字段标签行（左「后端推理实例」、右「权重比例」）→ 1px 分隔线 → 实例行列表（行间仅水平分隔线，行高 56px）→ 可选底部校验条。两个策略视图共享同一组字段标签；**不使用列间竖线**：实例数通常为 2~3，竖线属冗余信息。实例名列在三种策略中共享相同起始位置：蓝绿发布的单选圆点绝对定位在行首，不占用实例列宽度。
- **常规路由（按权重分发）**：开启后默认选中，策略分段控件为单项只读态（不可点击、`tabIndex=-1`），外观与灰度发布的选中项完全一致（同圆角、同内边距、同白底蓝字选中态）。每行呈「实例名称（自适应省略）+ 权重 Stepper（输入框 84px + 上下步进 ±1）+ %」，**不展示占比进度条**（选择与数值本身已足够表达，避免行内图形噪音）。支持任意数量（含 1）的后端推理实例；**手动增删实例时自动按最新实例数量均分 100%**（编辑态首次进入保留已保存的自定义权重，仅在用户手动增删实例列表后重新均分）。单实例权重输入上限 100%（超出自动截断，禁止出现 `9999%` 之类的无意义输入）。**仅当已选择实例且合计 ≠ 100% 时**面板底部出现红色校验条「还差 N% / 已超出 N%，各实例权重之和必须等于 100%」，合计 100% 时无任何常驻说明文案。未选择任何实例时列表区展示空态「请先在上方选择后端推理实例」，且不展示权重校验条。
- **灰度发布（金丝雀 / 蓝绿）**：面板顶栏用**双项分段控件**在「金丝雀发布」「蓝绿发布」间互斥切换（`role="tablist"` / `role="tab"` / `aria-selected`，选中项白底 + 主色文字 + `0 1px 3px` 投影），不再使用下拉框。灰度发布固定为两个实例：① **金丝雀发布**：两实例权重自动互补（`baseline = 100% - canary`），步进 ±5，任一侧输入都会被 clamp 到 0~100 后反算另一侧；② **蓝绿发布**：采用业界主流的 **Active / Standby 单选模型**（参考阿里云 MSE、AWS 控制台），不展示权重输入框，改为两行可点击的单选行（行首单选圆点 + 实例名 + 行尾 `100%` / `0%`），点击任意一行秒级切换流量指向。单选行具备 `role="radio"` / `aria-checked` / `tabIndex` / Enter 与空格切换 / `focus-visible` 高亮，键盘可达。**仅当选中恰好 2 个后端推理实例时「灰度发布策略」单选可用**；实例数为 0、1 或 ≥3 时该单选置灰禁用；若已选灰度发布后实例数变为非 2，自动回退为「常规路由策略」。
- **后端推理实例可用性约束**：下拉列表中「已关机」实例整行置灰禁用（`cursor-not-allowed`），状态显示「已关机（不可选）」，不可勾选参与路由；仅「运行中」实例可被选入流量分发策略。
- **高可用与安全 · 模型Fallback联动**：常规路由策略（或单实例未开启流量分发策略）下保留「模型Fallback」兜底配置（支持选择内部/外部推理实例及运行中的兜底推理实例）；灰度发布策略下同样保留「模型Fallback」兜底配置（不再隐藏/自动关闭）。保留全局限流（RPM）及请求超时时间配置。
