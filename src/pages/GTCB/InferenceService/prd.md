## 1. 页面定位

推理实例是「算力加速平台-弹性扩缩容」中模型服务能力的落地页：以卡片形式展示已创建的推理服务实例，支持启动/停止/编辑/删除，并跳转 Ray 控制台。

页面副标题（原文）：支持从模型广场部署官方内置模型和用户上传模型，并支持远程拉取开源社区模型部署。

## 2. 信息架构

界面自外向内三层：顶栏（产品标识 + 管理工作台 + 语言/租户/用户）、左侧两级导航（算力平台 / 基础资源 / 算力评测）、右侧内容区（标题 → Tab → 工具栏 → 卡片网格 → 分页）。

**FR-6 创建内部推理服务（表单页）**

| 项目 | 说明 |
|---|---|
| 入口 | 列表页工具栏「创建」→ 进入创建页；页头返回箭头 / 底部「取消」「创建」→ 回到列表 |
| 基本信息 | 部署场景（中心部署 / 边缘部署，单选）；服务名称（必填，0/56 字数限制）；推理框架（必填，vLLM / KTransformer，附 CPU offload 选型提示）；选择模型（必填，官方模型 / 私有模型 + 模型下拉）；描述（0/500） |
| 算力规格（多厂商） | 表格中除英伟达 H100 外，补充了 **华为昇腾 910B、Metax C500、寒武纪 MLU370-X8、海光 DCU Z100、天数智芯 BI-V150** 五款机型（原型示例数据，显存/CPU/内存为占位值）；选中哪一行，指标模式的「算力型号」就取哪一行 |
| 内置指标（多厂商） | NVIDIA 走 DCGM，提供 7 个指标；**其它厂商只提供跨厂商口径统一的 2 个：算力利用率 + 显存使用率**（SM 活跃度/Tensor Core 是 NVIDIA 专有概念，昇腾为 AI Core/Cube，不通用）；指标名与 PromQL 为占位，需按各家 exporter 实际暴露替换 |
| 资源规格 | 资源池（必填）；负载优先级（必填，低/中/高/最高 分段选择，附三条说明）；算力型号（全部 / 英伟达 H100）；算力数量（全部 / 1 / 2）；算力规格（必填，单选的显卡规格表：型号/虚拟化类型/数量/比例/显存/CPU/内存/系统盘/显存超分/高速网络）；共享内存（必填，组合输入框：左侧「内存百分比」灰色 addon + 数值 + 右侧「%」addon，外部显示换算值 0.00Gi，默认 25）；当前资源池是否允许抢占的「否」为红色警示；组调度（启用开关 + 说明）；拓扑感知调度（节点内拓扑亲和）；指定加速卡调度（多选） |
| 推理配置 | 服务模型名称（必填，名称 + 版本两个输入）；部署模式（必填，简易模式 / 分布式并行 两选一，附适用说明，选中项标题蓝色）；高级配置（加粗蓝色文字 + 方框「+」按钮，展开后图标变「−」，展开区为配置项占位） |
| 模型并行（仅分布式并行时出现） | 必填；四列：TP并行（张量并行数）、PP并行（流水线并行数）、DP并行（数据并行数）、EP并行（启用复选框），每项带 ⓘ 说明；下方浅蓝说明面板三条：①稠密模型/MoE 模型的 TP/DP/PP 选型建议与 EP 开启条件（TP × DP > 1）②服务总卡数 = 模型副本数 × TP × PP × DP（EP 不影响卡数）③Pod 数量 =（模型副本 × TP × PP × DP）/ 规格卡数，且规格卡数必须能被（TP × PP × DP）整除 |
| 弹性伸缩 | 分区标题带说明「弹性伸缩最小单元是一个模型副本，通过调整模型副本数实现扩缩容」。弹性模式（必填，三选一，选中项文字变蓝）：<br>· **常规模式**：说明「一般用于稳定负载，无需频繁扩缩容场景」；只展示 模型副本数（必填，数字 + 步进）<br>· **Serverless 模式**：说明「一般用于负载变化较大场景，根据请求情况自动扩缩容，无需人工干预」；展示 最小模型副本、最大模型副本、缩容检测窗口（秒，默认 600，对应 `downscaleDelayS`）、目标请求数（默认 10.0）、最大请求数（默认 20.0）<br>· **指标模式**：与 Serverless 同构的表单样式，按 GPU 指标调整**模型副本范围**（副本数决定卡数，worker 由副本数自动换算）。**监控指标**——算力型号（只读标签，值取自「算力规格」选中行）、指标来源（内置/自定义 PromQL）、指标 + 聚合方式（avg/max/sum）、指标说明；**扩缩参数**——最小模型副本数（596px 输入 + ↑，ⓘ「缩容时最少保留的模型副本数」，**校验不得为 0**）、最大模型副本数（596px 输入 + ↑；三种动态提示：①「扩容时最多允许的模型副本数」②**最小 = 最大时**「最大与最小相等：副本数固定，等同于常规模式（无弹性）」③**最小 > 最大时**红字「最大模型副本数不能小于最小模型副本数」）、缩容检测窗口（秒，ⓘ「指标持续低于缩容阈值达到该时长后，才收窄副本上限」）、扩容阈值（当指标 ≥ N + 单位，默认取指标推荐值）、缩容阈值（当指标 ≤ N + 单位，默认取推荐值的 37.5%）；**校验：扩容阈值必须严格大于缩容阈值**，相等或倒置时在缩容阈值下方红字提示「扩容阈值必须大于缩容阈值（当前 X ≤ Y）：相等会来回震荡，倒置会让两个条件同时成立」；不提供扩容检测窗口与高级配置 | |
| 业务规则 | 1) 必填项以红色 * 标识，未填不可提交（原型仅做视觉约束） 2) 算力规格为单选，选中行高亮 3) 弹性伸缩最小单元为一个模型副本；模型并行仅在「分布式并行」下展示 4) 复选框选中态为蓝底白色对号；单选选中态为实心蓝底白点 5) 组调度的说明文案与「启用」同行，其余字段说明在控件下方 6) 页头为「← ｜ 标题」结构并带下边线 |
